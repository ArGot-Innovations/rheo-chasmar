I. The Discrete Substrate: Hyperdimensional Foundations
The substrate layer utilizes Hyperdimensional Computing (HDC) and Vector Symbolic Architecture (VSA) principles to map data into noise-resistant, holographic representations.
1.1 Bit-Plane Storage Architecture
Hypervectors are stored as three parallel bit-planes over an asserted coordinate space (typically 1024 coordinates):
* Sign Plane (  $P_s$  ) : Determines the polarity.
* Magnitude-1 Plane (  $P_1$  ) : Represents the first level of intensity.
* Magnitude-2 Plane (  $P_2$  ) : Represents the second level of intensity.This layout is optimized for hardware using 64-bit unsigned integers, requiring 48 machine words per hypervector. This structure allows for efficient SIMD and POPCNT operations essential for Multiply-Add-Permute (MAP) algebra.
1.2 Magnitude Overflow and Canonical Repair
The original positional-binary mapping ( $H_i = (-1)^{P_si} \cdot ( 1 \cdot P_1i + 2 \cdot P_2i )$ ) was found to be defective, as it produced a septenary image (values from -3 to 3). This violated the system's declared quinary alphabet ( $Q = \{-2, -1, 0, 1, 2\}$ ).
* The Defect:  The (1, 1) codepoint produced out-of-bounds values that could cause actuator over-torquing.
* The Repair:  Implementation of a "high-wins" decode rule and a write-path invariant enforcing bit-plane orthogonality.
* Corrected Equation:   $H_i = (-1)^{P_si} \cdot [ (P_1i \wedge \neg P_2i) + 2 \cdot P_2i ]$ . This ensures the image is strictly bound to the quinary space.
1.3 Graded Similarity Metrics
Early iterations utilized XNOR logic gates or sign concordance, which measured exact symbolic equality rather than gradation. In high-dimensional VSA spaces, a proper metric must differentiate between small magnitude variations and total polar oppositions.
* Canonical Solution:  A decoded cosine similarity operating over active quinary values.

III. Cyber-Physical Actuation and Safety
The interface between theoretical control and the physical robotic plant requires robust, state-aware formulations to prevent hardware destruction.
3.1 Closed-Loop Actuation
Static feedforward maps are insufficient for physical deployment as they lead to actuator saturation and integral windup.
* Dynamic Back-Calculation:  To prevent windup, the error difference between saturated and unsaturated signals must be routed back through a tracking time constant to unwind the integrator state.
* Kinematic Limits:  Strict acceleration and jerk limits ( $\| \dot{u} \|\infty \leq R{max}$  and  $\| \ddot{u} \|\infty \leq J{max}$ ) protect hardware during rapid cognitive shifts.
3.2 Control Barrier Functions (CBF)
Heuristic failsafes (such as abrupt 70% bitwise-AND masking) are rejected due to the destructive transients they induce. Instead, the architecture adopts  Control Barrier Functions (CBFs) .
* Mechanism:  CBFs solve a Quadratic Program (QP) at each control step to project nominal commands onto a forward-invariant safe set.
* Safety Guarantees:  These functions ensure trajectories never exit predefined safe regions regarding energy availability, actuator load, and identity drift.
