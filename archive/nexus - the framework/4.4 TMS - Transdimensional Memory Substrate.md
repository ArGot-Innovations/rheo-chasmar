### 4.4 TMS - Transdimensional Memory Substrate

TMS is the mandatory live storage and memory continuum for active HVD state. Its canonical active path is log-structured:

```text
mutation
  |
  v
WAL -> Memtable -> Immutable SSTables -> Compaction / Reconsolidation
  |          |             |
  +----------+-------------+--> active HVD read/query views
                                  |
                                  +--> derived ANN/HNSW indexes
```

In the revised architecture, TMS is broader than an ordinary storage backend. It is responsible not only for persistence mechanics, but also for the current substrate realization of logically identified HVDs.

Let `ID(D_i)` denote the stable logical identity of HVD `D_i`. The time-dependent TMS realization function may then be written abstractly as

```text
rho_t : ID(D_i) -> R_i(t)
```

where `R_i(t)` is the realization descriptor of `D_i` at time `t`.

Because an HVD may occupy several realization modes simultaneously, `R_i(t)` is not necessarily a single-valued state. Instead,

```text
R_i(t) subseteq {
    resident,
    COW-shared,
    device-backed,
    replicated,
    archive-staged,
    ...
}
```

Thus, an HVD may, for example, be resident, COW-shared, and replicated at the same time. TMS may later compact, migrate, replicate, materialize, evict, or stage portions of that HVD, producing a different realization descriptor:

```text
rho_t(ID(D_i)) != rho_(t+1)(ID(D_i))
```

without thereby creating a new logical HVD.

The defining invariant is therefore:

```text
change in realization !=> change in logical identity
```

or, more explicitly,

```text
rho_t(ID(D_i)) != rho_(t+1)(ID(D_i))
    !=>
ID(D_i,t) != ID(D_i,t+1)
```

A change in substrate realization does not, by itself, constitute a change in logical HVD identity.

This distinction allows TMS to move, compact, replicate, share, stage, or otherwise reorganize the physical realization of an HVD while preserving the HVD as the same logical database. Identity and realization are therefore deliberately separated:

```text
logical identity != physical realization
```

TMS owns the latter. Changes to the former require identity- or continuity-relevant semantics beyond ordinary storage movement.
