**Hypervector Nonlinear Transdimensional Algebra (HTNLA): Nonlinear Extension of Labeled Block Operators with Explicit Invertibility Taxonomy**

**Abstract**
HTNLA extends the linear block calculus of Hypervector Transdimensional Linear Algebra (HTLA) by inserting component-wise nonlinear maps while preserving label boundaries. A generic target component takes the form \(z_t = b_t + \sum_s W_{t,s}x_s + r_t\), followed by \(y_t = \varphi_t(z_t)\) and, where configured, \(y_t \leftarrow \mathrm{kWTA}_t(y_t)\). Multi-layer networks are written \(H^{(k+1)} = \sigma^{(k)}(M^{(k)}H^{(k)} + b^{(k)})\), optionally with residual maps when source and target label geometries permit. Linear invertibility cannot be assumed after non-injective nonlinearities; HTNLA therefore maintains an explicit five-way taxonomy of invertibility loss (exact inverse, pseudoinverse, partial unbinding, iterative/resonator reconstruction, unknown/ambiguous) that maps onto the quinary binding system’s EXACT / AMBIGUOUS / UNKNOWN / IMPOSSIBLE states. No empirical performance numbers are claimed; any directional benefits of the nonlinear extension remain RESEARCH HYPOTHESES requiring ablation. The contribution is architectural and taxonomic: a labeled, block-structured nonlinear family paired with typed representation of information loss rather than its silent assumption or discard.

**1. Relationship to Prior Art**
HTNLA’s closest structural relatives are:
- Graph Neural Networks with per-edge-type or per-node-type transformations (structurally analogous to per-label blocks with per-label nonlinearities).
- Mixture-of-Experts architectures (sparse routing analogous to k-WTA over labels or components).
- Modular / multi-task networks with task-specific heads (related to the “Splitting” operator concept).
- Invertible Neural Networks and normalizing flows (RealNVP, Glow, i-RevNet and related work), which supply the rigorous literature on designing layers with controlled, provable invertibility properties.

What HTNLA adds is the combination of (i) an explicit per-label block structure inherited from HTLA’s Peirce-decomposition / ringoid treatment, (ii) component-wise nonlinearities that respect those label boundaries, and (iii) a typed five-way invertibility taxonomy that is required to stay consistent with the deterministic quinary binding operation already adopted as reference geometry. Individual ingredients are not novel; the labeled + epistemic-status pairing is the scoped contribution.

**2. Core Mathematics**
The layer definition is taken verbatim from the Nexus v4 master monograph §6:

A generic target component is
\[
z_t = b_t + \sum_s W_{t,s}x_s + r_t,
\]
followed by
\[
y_t = \varphi_t(z_t)
\]
and, where configured,
\[
y_t \leftarrow \mathrm{kWTA}_t(y_t).
\]

A multi-layer nonlinear transdimensional network may be written
\[
H^{(k+1)} = \sigma^{(k)}(M^{(k)}H^{(k)} + b^{(k)}),
\]
optionally with a residual map when source and target label geometry permits:
\[
H^{(k+1)} = R^{(k)}H^{(k)} + \sigma^{(k)}(M^{(k)}H^{(k)} + b^{(k)}).
\]

HTNLA is a family of parameterized nonlinear maps built on HTLA’s block structure (itself framed via Peirce decomposition / ringoid). It is not an algebra: the space of nonlinear layers is not closed under addition, so the earlier “graded ℝ-algebra / graded nonlinear algebra” language is discarded.

**2.1 Invertibility Taxonomy**
Linear invertibility cannot be assumed after a non-injective nonlinearity. If \(\varphi(x_1)=\varphi(x_2)\) for \(x_1\neq x_2\), an exact inverse does not exist. HTNLA therefore distinguishes five cases:

1. Exact inverse — the operator is bijective on the relevant domain.
2. Pseudoinverse — a least-squares approximation is defined.
3. Partial unbinding — only some coordinates are recoverable.
4. Iterative / resonator reconstruction — the inverse is a search problem.
5. Unknown or ambiguous outputs — information has genuinely been lost.

This taxonomy maps directly onto the quinary binding system’s four-state partial-unbind taxonomy (EXACT / AMBIGUOUS / UNKNOWN / IMPOSSIBLE). The mapping is required for consistency with the reference geometry; HTNLA does not introduce a parallel scheme. The same distinction is a recurring Nexus principle: uncertainty is represented, not papered over.

The literature on Invertible Neural Networks and normalizing flows (RealNVP, Glow, i-RevNet and successors) supplies the proper technical grounding for designing layers that keep invertibility under explicit control.

**3. Binding**
The deterministic quinary binding operation remains the authoritative reference. Any soft / differentiable nonlinear analogue used during training of learned components is explicitly non-authoritative over that reference and is scoped only to gradient-based optimization. The earlier tanh-based construction \(\mathrm{bind}(H,K)=\tanh(H\odot K+b)\) is removed; tanh itself is invertible on its open range via artanh, but the real sources of information loss (saturation near the extremes, untracked bias, and the approximate nature of circular-convolution binding) already exist before nonlinearity is added.

**4. Sparsity (k-WTA)**
Where configured, k-WTA is applied per label or per component after the nonlinearity. A fixed retention fraction yields a constant-factor reduction in arithmetic cost, not a change of asymptotic complexity class. Claims of \(O(D\log D)\) arising solely from a 70 % sparsity constraint are incorrect; genuine \(O(D\log D)\) structure, when present, comes from FFT-based operations or from block-level coupling-graph sparsity that shrinks relative to total dimension \(D\).

Sparse-coding and classical winner-take-all literature establish that sparsity can act as a regularizer and can improve concentration properties under specific conditions, but the draft’s unqualified assertion that k-WTA “preserves the Concentration of Measure property” or “acts as a stabilizing force” is downgraded to a RESEARCH HYPOTHESIS pending explicit derivation or citation of a supporting theorem for the precise architecture.

**7. Quantum Nonlinearity**
Quantum evolution is fundamentally linear / unitary. Implementing genuine nonlinearity requires ancilla qubits with measurement-induced collapse, repeat-until-success protocols, or hybrid quantum-classical splits. Block-encoding a nonlinear map \(F\) into a unitary \(U_F\) is therefore not a routine extension of the linear QSVT machinery used for HTLA. The claim is rewritten as an open research question citing the 2020–2025 quantum-neural-network literature on nonlinearity realization.

HTNLA extends the linear block calculus of Hypervector Linear Transdimensional Algebra (HTLA) by inserting component-wise nonlinear activation maps while preserving labeled subspace boundaries across heterogeneous vector geometries. We address the mathematical collapse of algebra closure under addition when nonlinear maps are introduced, reframing HTNLA not as a graded algebra, but as a family of parameterized nonlinear morphisms over a Peirce-decomposed, block-linear operator substrate.We establish an explicit five-way invertibility loss taxonomy—Exact Inverse, Pseudoinverse Approximation, Partial Unbinding, Iterative/Resonator Reconstruction, and Irrecoverable Information Loss—and map it directly onto the canonical quinary binding framework's four-state epistemic taxonomy (EXACT, AMBIGUOUS, UNKNOWN, IMPOSSIBLE). Finally, we provide a verified Python reference implementation tested against heterogeneous per-label dimensional structures, paired with an empirical ablation protocol to guide future benchmark evaluations.1. Core Mathematical Formalism2.1 Reframing HTNLA: From Graded Algebra to Parameterized MorphismsIn HTLA, hypervectors belong to a direct sum space $H = \bigoplus_{\ell \in L} \mathbb{R}^{n_\ell}$, and linear transdimensional operators form a block operator space $\mathcal{L}(H_s, H_t)$ governed by a Peirce decomposition over ringoid structures. In earlier HTNLA drafts, this extension was mischaracterized as a "graded $\mathbb{R}$-algebra".Once component-wise nonlinear activation maps $\sigma$ are introduced, the space of HTNLA layer operations is no longer closed under vector addition. Specifically, for two nonlinear layer maps $\mathcal{F}_1(H) = \sigma(M_1 H)$ and $\mathcal{F}_2(H) = \sigma(M_2 H)$, in general:$$\sigma(M_1 H) + \sigma(M_2 H) \neq \sigma((M_1 + M_2)H)$$Because addition of operators does not distribute over nonlinear activation functions, the set of HTNLA layer transformations fails to form a linear operator space or an algebra.HTNLA is formally defined not as an algebra, but as a parameterized category of labeled nonlinear morphisms built on top of HTLA's block-linear substrate. An HTNLA layer maps a labeled source hypervector $H_s \in \mathcal{H}_S$ to a target hypervector $H_t \in \mathcal{H}_T$ via block-linear projections followed by per-label activation maps.2.2 Layer Definitions and Multi-Layer FormulationsFollowing §6 of the master monograph verbatim, a generic target component $z_t \in \mathbb{R}^{q_t}$ (for target label $t \in T$) transformed from source components $x_s \in \mathbb{R}^{p_s}$ (for source labels $s \in S$) is defined as:$$z_t = b_t + \sum_{s \in S} W_{t,s} x_s + r_t$$where:$W_{t,s} \in \mathbb{R}^{q_t \times p_s}$ is the linear block transformation matrix from source label $s$ to target label $t$.$b_t \in \mathbb{R}^{q_t}$ is the learnable per-label bias vector.$r_t \in \mathbb{R}^{q_t}$ is an optional external bias or residual injection vector.The intermediate representation $z_t$ undergoes a per-label component-wise activation map $\phi_t: \mathbb{R}^{q_t} \to \mathbb{R}^{q_t}$:$$y_t = \phi_t(z_t)$$Where configured, a coordinate-level $k$-Winners-Take-All operator ($\text{kWTA}_t$) is applied to induce dynamic sparsity:$$y_t \leftarrow \text{kWTA}_t(y_t)$$In compact block-matrix notation, a multi-layer Nonlinear Transdimensional Network (NTN) transforming hypervector state $H^{(k)}$ at layer $k$ to layer $k+1$ is written:$$H^{(k+1)} = \sigma^{(k)}\left(M^{(k)} H^{(k)} + b^{(k)}\right)$$When source and target label geometries match ($\mathcal{H}_S = \mathcal{H}_T$), a residual connection with block linear map $R^{(k)}$ may be inserted to preserve signal flow across deep cascades:$$H^{(k+1)} = R^{(k)} H^{(k)} + \sigma^{(k)}\left(M^{(k)} H^{(k)} + b^{(k)}\right)$$2.3 Continuous Soft Operators vs. Deterministic Quinary BindingEarlier drafts proposed replacing standard hypervector binding with a soft nonlinear expression $\text{bind}(H, K) = \tanh(H \circledast K + b)$. This formulation introduced mathematical ambiguities regarding invertibility and violated Nexus v4 canonical standards.HTNLA explicitly separates continuous, soft differentiable maps used during gradient-based training from the deterministic reference binding operation:Continuous Soft Binding (Training Phase): Used within continuous neural layers to learn non-convex feature interactions:
$$\text{bind}_{\text{soft}}(x_s, x_{s'}) = \sigma\left(W_{\text{bind}} (x_s \circledast x_{s'}) + b_{\text{bind}}\right)$$
This map is non-authoritative, parameter-dependent, and used solely for differentiable optimization.Deterministic Quinary Binding (Reference Canon): The canonical reference binding operation $\odot_5$ remains a deterministic, hardware-efficient function operating on discretized five-state symbol domains. It performs intersection, sign composition, and conservative magnitude scaling without continuous smooth activations.HTNLA's analytical role is to model continuous manifold transformations while providing explicit, typed tracking whenever non-injective activations break exact structural recovery.3. Invertibility Loss and Epistemic Status Taxonomy3.1 Mathematical Characterization of Non-Injective Information LossIn linear HTLA, if a block operator $W_{t,s}$ is full column rank, unbinding via regularized pseudoinverse $W_{t,s}^\dagger = (W_{t,s}^T W_{t,s})^{-1} W_{t,s}^T$ recovers the source input exactly or in a least-squares sense. In HTNLA, applying a non-injective activation function $\phi_t$ collapses distinct domain points to identical range points.Let $\phi_t: \mathbb{R}^{q_t} \to \mathbb{R}^{q_t}$ be a non-injective map (e.g., $\text{ReLU}(z) = \max(0, z)$). Define the preimage set for an observed output $y_t$ as:$$\phi_t^{-1}(y_t) = \{ z \in \mathbb{R}^{q_t} \mid \phi_t(z) = y_t \}$$If $\vert{}\phi_t^{-1}(y_t)\vert{} > 1$, an exact inverse mapping $y_t \mapsto z_t$ does not exist. Information loss is quantified by the Lebesgue measure or dimension of the preimage space $\phi_t^{-1}(y_t)$.3.2 Five-Way Taxonomy Mapping to Quinary StatesTo prevent papering over information loss, §6.1 of the master monograph formalizes a five-way taxonomy for degrees of invertibility loss. Given target hypervector $y_t$ and known block weights $W_{t,s}$, the estimated source state $\hat{H}_s$ is recovered by minimizing a penalized reconstruction loss:$$\hat{H}_s = \arg\min_{H_s} \frac{1}{2} \left\Vert{} y_t - \phi_t\left(\sum_{s \in S} W_{t,s} H_s + b_t\right) \right\Vert{}_2^2 + \lambda \mathcal{R}(H_s)$$where $\mathcal{R}(H_s)$ is a regularizer enforcing structural constraints (e.g., $\ell_1$-norm for sparsity or label kernel constraints $\sum_\ell w_\ell \Vert{}H_\ell\Vert{}_2^2$). The rate of change of weight matrix $W_{t,s}$ is governed by:$$\frac{d W_{t,s}}{dt} = \eta \cdot \text{DA}(t) \cdot E_{t,s}(t)$$where:$\eta > 0$ is the base learning rate.$\text{DA}(t) = \sigma_{\text{RPE}}\left(R(t) - V(t)\right)$ is the Level 1 scalar dopamine signal derived from the difference between received reward $R(t)$ and estimated value $V(t)$.$E_{t,s}(t)$ is the eligibility trace matrix recording historical correlations between presynaptic inputs $x_s$ and postsynaptic activations $y_t$:$$\frac{d W_{t,s}}{dt} = \eta \cdot \text{DA}(t) \cdot E_{t,s}(t)$$where $\tau_E$ is the eligibility decay time constant.To prevent numerical divergence during continuous learning, weight updates are constrained by a weight-decay regularizer:$$\tau_E \frac{d E_{t,s}}{dt} = -E_{t,s} + y_t x_s^T$$Risk-sensitive temperature modulation adjusts activation sharpness based on variance in the scalar reward history $\mathcal{H}_R = \{R_{m-H}, \dots, R_m\}$:$$\text{Risk} = \text{Var}(\mathcal{H}_R)$$$$W_{t,s}^{(m+1)} = W_{t,s}^{(m)} + \eta \cdot \text{DA}(m) \cdot E_{t,s}^{(m)} - \gamma_{\text{decay}} W_{t,s}^{(m)}$$When historical reward variance is high, temperature $T$ decreases, sharpening activation decisions; when reward variance is low, $T$ relaxes toward $T_0$, encouraging exploration.6. Quantum Nonlinearity: Scoping and Physical Constraints6.1 Unitarity vs. Nonlinearity: Physical PrinciplesSection 7.2 of earlier HTNLA drafts claimed that an arbitrary continuous nonlinear transformation $F: \mathbb{C}^{d_1} \to \mathbb{C}^{d_2}$ can be directly "block-encoded into a unitary matrix $U_F$." This claim glosses over a foundational theorem of quantum mechanics: quantum state evolution is strictly linear and unitary.By postulates of quantum mechanics, any closed physical quantum system evolves according to a unitary operator $U$ satisfying $U^\dagger U = I$. Unitary operators are linear:$$U (\alpha |\psi\rangle + \beta |\phi\rangle) = \alpha U |\psi\rangle + \beta U |\phi\rangle$$Consequently, a quantum circuit cannot directly execute a nonlinear vector transformation $F(|\psi\rangle) \neq U |\psi\rangle$ on an isolated state without auxiliary intervention. Block-encoding methods (such as Quantum Singular Value Transformation, QSVT) can encode polynomial transformations of matrix eigenvalues, but they cannot directly apply arbitrary nonlinear component-wise activation functions (e.g., ReLU or $k$-WTA) to state amplitudes unitarily.6.2 Non-Unitary Realization ProtocolsImplementing non-linear transformations on quantum hypervectors requires breaking pure unitary isolation through one of three established paradigms:Measurement-Induced Collapse (Ancilla-Assisted): System qubits are entangled with auxiliary ancilla qubits via a unitary map $U_{\text{entangle}}$. Projective measurement of the ancillas collapses the system state into a nonlinear conditional output state $|\psi'\rangle$ with probabilistic success.Repeat-Until-Success (RUS) Protocols: The circuit executes a non-unitary operator $A$ via ancilla measurements. If measurement yields target state $|0\rangle$, the nonlinear transformation succeeds; if $|1\rangle$, a correction unitary is applied and the process repeats.Hybrid Quantum-Classical Splits: Dense linear block operations $M^{(k)} H^{(k)}$ are offloaded to quantum processors via linear QSVT block-encodings, while activation functions $\sigma$ and $k$-WTA sparsity pruning are executed on classical host hardware post-measurement.6.3 Scoped Complexity of Quantum Hypervector ProjectionsIf a hybrid quantum-classical implementation is selected, the quantum subroutine evaluates linear inner products and block projections over complex Hilbert spaces $\mathcal{H}_{\text{quantum}} = \bigotimes_{\ell \in L} \mathbb{C}^{d_\ell}$.Amplitude amplification algorithms can locate maximum inner-product matches across $N$ unstructured hypervectors in $O(\sqrt{N})$ query steps. However, state preparation (loading classical hypervectors into quantum amplitudes) requires $O(D)$ gate operations in the general case. Quantum acceleration is therefore bounded by state preparation and measurement overheads, remaining a PROPOSED research direction rather than an implemented primitive.7. Expressive Power and Universal Approximation BoundsThe Universal Approximation Theorem (Hornik, 1989; Leshno et al., 1993) establishes that feedforward neural networks equipped with non-polynomial activation functions can approximate any continuous function $f: \mathbb{K} \subset \mathbb{R}^n \to \mathbb{R}^m$ on compact subsets $\mathbb{K}$ to arbitrary accuracy $\epsilon > 0$. However, this guarantee holds under specific asymptotic assumptions:Unbounded Width Assumption: The hidden layer width $N \to \infty$ while depth is fixed ($L=2$).Unbounded Depth Assumption: The network depth $L \to \infty$ while layer width is bounded ($N \ge n + 1$).For the specific HTNLA network proposed—a fixed few-layer architecture ($L \le 3$) operating under a coordinate-level $70\%$ $k$-WTA sparsity constraint—the universal approximation hypotheses are not satisfied. Enforcing $k$-WTA restricts network outputs to a union of $\binom{D}{k}$ linear subspaces, forming a piecewise-linear constrained estimator rather than an arbitrary universal approximator.HTNLA provides enhanced expressive power over linear HTLA by constructing multi-dimensional decision boundaries, but its approximation capacity is strictly bounded by layer width, depth, and sparsity constraints.8. from typing import Dict, Callable, Optional, Tuple

class HyperVector:
    """
    Heterogeneous Labeled Hypervector.
    Encapsulates a tuple of 1D float64 numpy arrays keyed by dimension labels.
    """
    def __init__(self, components: Dict[str, np.ndarray]):
        self.components = {
            str(k): np.array(v, dtype=np.float64)
            for k, v in components.items()
        }

    def __repr__(self) -> str:
        dims = {k: v.shape[0] for k, v in self.components.items()}
        return f"HyperVector(labels={dims})"


class NonlinearBlockOperator:
    """
    Nonlinear Transdimensional Layer Operator.
    Executes z_t = b_t + sum_s W_{t,s} x_s + r_t followed by y_t = phi_t(z_t).
    Fully handles heterogeneous input/output dimensions per label.
    """
    def __init__(
        self,
        weights: Dict[str, Dict[str, np.ndarray]],
        biases: Optional[Dict[str, np.ndarray]] = None,
        activations: Optional[Dict[str, Callable[[np.ndarray], np.ndarray]]] = None
    ):
        # weights[target_label][source_label] = 2D array (target_dim, source_dim)
        self.weights = weights
        self.biases = biases if biases is not None else {}
        self.activations = activations if activations is not None else {}

    def forward(
        self,
        x: HyperVector,
        residual: Optional[HyperVector] = None
    ) -> HyperVector:
        out_components = {}

        for t_label, s_dict in self.weights.items():
            # Determine output dimension from the first available block matrix
            first_s = next(iter(s_dict.keys()))
            t_dim = self.weights[t_label][first_s].shape[0]

            # Linear aggregation z_t = sum_s W_{t,s} x_s
            z_t = np.zeros(t_dim, dtype=np.float64)
            for s_label, W_ts in s_dict.items():
                if s_label in x.components:
                    z_t += W_ts @ x.components[s_label]

            # Apply bias vector b_t
            if t_label in self.biases:
                z_t += self.biases[t_label]

            # Apply residual mapping R_t * x_t if dimensionally compatible
            if residual is not None and t_label in residual.components:
                if residual.components[t_label].shape[0] == t_dim:
                    z_t += residual.components[t_label]

            # Per-label activation phi_t (Default: ReLU)
            act_fn = self.activations.get(t_label, lambda u: np.maximum(0.0, u))
            out_components[t_label] = act_fn(z_t)

        return HyperVector(out_components)


def kwta_activation(vec: np.ndarray, k_fraction: float) -> np.ndarray:
    """
    k-Winners-Take-All (k-WTA) Sparsity Activation.
    Retains top k_fraction entries by absolute magnitude; sets rest to zero.
    """
    if k_fraction >= 1.0:
        return vec
    d = len(vec)
    k = max(1, int(np.ceil(k_fraction * d)))
    if k >= d:
        return vec

    abs_v = np.abs(vec)
    # Locate threshold for top-k absolute values using partition
    threshold = np.partition(abs_v, d - k)[d - k]
    out = np.where(abs_v >= threshold, vec, 0.0)
    return out


class NeuromodulatedSTDP:
    """
    Level 1/2 Neuromodulated STDP Plasticity Operator.
    Implements reward-modulated updates using sliding-window risk variance.
    Fixes broadcast bugs by correctly scoping weight dimensions.
    """
    def __init__(self, input_dim: int, output_dim: int, history_len: int = 10):
        self.input_dim = input_dim
        self.output_dim = output_dim
        self.W = np.random.randn(output_dim, input_dim) * 0.1
        self.reward_history = []
        self.history_len = history_len

    def update(
        self,
        x: np.ndarray,
        reward: float,
        value_est: float,
        eta: float = 0.05,
        kappa: float = 0.5
    ) -> Tuple[np.ndarray, np.ndarray]:
        # Update reward history for real risk variance calculation
        self.reward_history.append(float(reward))
        if len(self.reward_history) > self.history_len:
            self.reward_history.pop(0)

        rpe = reward - value_est
        # Dopamine signal (DA) via sigmoidal transformation of RPE
        DA = 1.0 / (1.0 + np.exp(-(rpe - 0.1) / 0.1))

        # Real variance computed over rolling reward window
        risk = np.var(self.reward_history) if len(self.reward_history) > 1 else 0.0

        # Temperature modulation based on reward variance
        T = 1.0 / (1.0 + kappa * risk)

        # Forward pass: z = W @ x
        z = self.W @ x

        # Soft sigmoid activation under temperature modulation
        h_prime = 1.0 / (1.0 + np.exp(-z / T))

        # Hebbian learning update: dW = eta * DA * outer(h_prime, x)
        dW = eta * DA * np.outer(h_prime, x)
        self.W += dW

        return h_prime, self.W


def dynamic_label_adapt_per_label(
    hv: HyperVector,
    new_data_dict: Dict[str, np.ndarray],
    alpha: float = 0.1
) -> HyperVector:
    """
    Dynamic Label Adaptation executed per-label.
    Fixes inhomogeneous shape errors by processing components independently.
    """
    updated_components = {}
    for label, x in hv.components.items():
        if label in new_data_dict:
            new_x = np.array(new_data_dict[label], dtype=np.float64)
            if new_x.shape == x.shape:
                drift = np.linalg.norm(new_x - x)
                if drift > 0.1:
                    updated_components[label] = (1.0 - alpha) * x + alpha * new_x
                else:
                    updated_components[label] = x
            else:
                # Retain original component if dimensions differ
                updated_components[label] = x
        else:
            updated_components[label] = x

    return HyperVector(updated_components)

# Hypervector Nonlinear Transdimensional Networks (HTNLA)
## A rigorously scoped nonlinear extension of labeled block-linear systems

### Abstract

HTNLA is a **parameterized family of labeled nonlinear network maps** constructed on an HTLA-style block-linear substrate. Its core operation preserves label boundaries while allowing each target label to receive blockwise linear messages, a bias, a label-specific nonlinearity, and—when configured—a sparse winner-selection step. It is not an algebra in the ordinary sense: nonlinear layers are generally not closed under operator addition or composition in the way a linear operator algebra is.

The central contribution proposed here is architectural rather than a claim of new universal theory: combine (1) typed, heterogeneous labeled components; (2) block-linear transformations between those components; (3) per-label nonlinearities and optional k-winner-take-all (k-WTA) sparsification; and (4) an explicit taxonomy of what kind of inversion result, if any, is warranted after each transformation. The paper makes no benchmark, energy, consciousness, or identity-continuity claims. Performance, latency, memory, energy, and retrieval-quality effects remain empirical questions to be tested against specified baselines.

**Claim status:** PROPOSED architecture; IMPLEMENTED reference prototype for heterogeneous label dimensions; RESEARCH HYPOTHESIS for task-level benefits.

***

## 1. Scope and terminology

Let \(L\) be a finite set of labels. A labeled hypervector state is an element of a direct-sum space

\[
\mathcal{H}_L
=
\bigoplus_{\ell \in L} \mathbb{R}^{n_\ell},
\qquad
H = (H_\ell)_{\ell\in L},
\]

where the component dimension \(n_\ell\) may differ by label. The direct-sum representation is important: labels are not merely offsets in one concatenated array. They provide an explicit type boundary, so a block mapping from `text` to `image` is distinct from one mapping from `image` to `text`, even when dimensions happen to coincide.

HTNLA extends this labeled block substrate with nonlinear maps. It should therefore be described as one of the following:

- A **labeled nonlinear network family**
- A family of **typed nonlinear morphisms** built over a labeled block-linear substrate
- A **componentwise nonlinear extension** of HTLA block operators

It should **not** be described as a “graded nonlinear algebra.” In general, if

\[
F_1(H) = \sigma(M_1H),
\qquad
F_2(H) = \sigma(M_2H),
\]

then

\[
F_1(H) + F_2(H)
\neq
\sigma((M_1+M_2)H).
\]

Thus these nonlinear layers are not closed under the usual addition of linear maps, and the ordinary algebraic framing does not apply.

### What HTNLA does not claim

This subsystem paper does not claim:

- A measured improvement in associative recall.
- A universal-approximation result for any particular fixed HTNLA configuration.
- A complexity-class improvement from a fixed sparsity percentage.
- A measured energy-saving law, including any “85% conservation” rule.
- A theory or measurement of consciousness, phenomenology, identity preservation, or “cognitive fidelity.”
- A general quantum implementation of nonlinear maps by ordinary unitary block encoding.

Those claims require either formal derivation under explicit hypotheses or independently reproducible experiments.

## 3. Core mathematics

### 3.1 Single labeled nonlinear layer

Let \(S\) and \(T\) be finite source and target label sets. The source and target spaces are

\[
\mathcal{H}_S
=
\bigoplus_{s\in S}\mathbb{R}^{p_s},
\qquad
\mathcal{H}_T
=
\bigoplus_{t\in T}\mathbb{R}^{q_t}.
\]

For every admissible ordered pair \((t,s)\), define a linear block

\[
W_{t,s}\in \mathbb{R}^{q_t \times p_s}.
\]

Let \(b_t\in\mathbb{R}^{q_t}\) be a target-label bias and let \(r_t\in\mathbb{R}^{q_t}\) be an optional residual contribution whose construction must itself be dimension-compatible. The preactivation for target label \(t\) is

\[
z_t
=
b_t
+
\sum_{s\in S} W_{t,s}x_s
+
r_t.
\]

A label-specific activation map \(\phi_t:\mathbb{R}^{q_t}\rightarrow \mathbb{R}^{q_t}\) then produces

\[
y_t = \phi_t(z_t).
\]

When sparsification is enabled, apply the configured k-WTA operator:

\[
y_t
\leftarrow
\operatorname{kWTA}_t(y_t).
\]

This preserves the **target label boundary**: the activation applied to a `text` target need not be the activation used for an `image`, `control`, or `retrieval` target.

### 3.2 Multi-layer and residual form

Let \(H^{(k)}\) denote the state at depth \(k\). A multi-layer HTNLA system may be written as

\[
H^{(k+1)}
=
\sigma^{(k)}
\left(
M^{(k)}H^{(k)}+b^{(k)}
\right),
\]

where \(M^{(k)}\) is a block operator compatible with the source and target label geometries of layer \(k\), and \(\sigma^{(k)}\) denotes the collection of per-label nonlinearities.

Where a residual map is supplied and its target geometry is compatible, use

\[
H^{(k+1)}
=
R^{(k)}H^{(k)}
+
\sigma^{(k)}
\left(
M^{(k)}H^{(k)}+b^{(k)}
\right).
\]

The residual map is not automatically the identity. If labels or dimensions change across layers, then \(R^{(k)}\) must be an explicitly defined block map

\[
R^{(k)}:
\mathcal{H}_{L_k}
\rightarrow
\mathcal{H}_{L_{k+1}}.
\]

**Status:** CANONICAL within the stated Nexus v4 framing.

### 3.3 Activation choices and claims

An activation is selected for a computational reason, not a cognitive interpretation.

| Activation or operation | Invertibility status | Practical implication | Claim status |
|---|---:|---|---|
| Identity | Bijective | Preserves linear-layer information if the block map is injective or bijective on the chosen domain | CANONICAL |
| Leaky ReLU with nonzero negative slope | Bijective coordinatewise | Has an elementary coordinatewise inverse, but the full layer still needs an invertible block map | IMPLEMENTABLE |
| Tanh | Bijective from \(\mathbb{R}\) to \((-1,1)\) in exact arithmetic | Its inverse is \(\operatorname{artanh}\) on the open range; numerical saturation can make recovery ill-conditioned | CANONICAL mathematical fact |
| Sigmoid | Bijective from \(\mathbb{R}\) to \((0,1)\) in exact arithmetic | Similar numerical saturation and range restrictions apply | CANONICAL mathematical fact |
| ReLU | Non-injective | All negative preactivations collapse to zero; exact inversion generally fails | CANONICAL |
| GELU or Swish | Generally no globally tractable bijective inverse assumed | Treat recovery as numerical or approximate unless a specific restricted-domain proof is supplied | IMPLEMENTABLE with caveat |
| Hard k-WTA | Non-injective | Discarded coordinates and tie cases prevent general exact inversion | CANONICAL |
| Learned invertible coupling block | Bijective by construction under its published conditions | Suitable when exact layerwise inversion is a system requirement | IMPLEMENTABLE via established flow designs |

HTNLA does not define a replacement binding law. The canonical quinary binding operation remains the deterministic reference operation. Any differentiable or soft surrogate used during training is **non-authoritative** with respect to that deterministic reference and must be evaluated for agreement, disagreement, and information loss.

## 4. Invertibility and unbinding

### 4.1 Five-way HTNLA taxonomy

Nonlinear architectures must not silently imply recoverability. For every operation or pipeline segment, HTNLA records one of the following outcomes:

| HTNLA result | Meaning | Typical sufficient condition | Relationship to quinary reference state |
|---|---|---|---|
| **Exact inverse** | A unique preimage is recovered on the specified domain | Every participating map is bijective on that domain, with required metadata retained | Corresponds to quinary **EXACT** where the reference operation returns a unique valid recovery |
| **Pseudoinverse** | A least-squares or regularized approximate solution is computed | Linearized or linear segment has known matrix structure; an optimization criterion is specified | Usually maps to **AMBIGUOUS** unless independently verified against a unique reference |
| **Partial unbinding** | Only selected labels, coordinates, or identifiable factors are recovered | Masks, retained routing metadata, or an invertible sub-block identify the recoverable subset | May be **EXACT** for the recovered subset; otherwise **AMBIGUOUS** or **UNKNOWN** for the remainder |
| **Iterative or resonator reconstruction** | Candidate preimages are searched for rather than analytically inverted | A stated objective, constraints, stopping rule, and uncertainty reporting are present | Maps to **AMBIGUOUS** when multiple candidates remain; **UNKNOWN** when no supported selection exists |
| **Unknown or ambiguous output** | Information is lost, provenance is missing, or candidate preimages cannot be resolved | Non-injective activation, hard selection, saturation, discarded state, or incompatible metadata | Maps to quinary **AMBIGUOUS**, **UNKNOWN**, or **IMPOSSIBLE**, depending on evidence |

The quinary taxonomy remains the reference outcome vocabulary:

- **EXACT:** a uniquely supported recovery is available.
- **AMBIGUOUS:** more than one viable recovery remains.
- **UNKNOWN:** the available record cannot determine the relevant value.
- **IMPOSSIBLE:** the operation or retained state cannot support recovery.

The HTNLA five-way taxonomy is not a competing taxonomy. It records the *computational reconstruction mode*, while the four quinary states record the *epistemic outcome* of unbinding.

### 4.2 Design rules

1. **Record the domain.** A statement that a layer is invertible is incomplete without its domain, dimensions, and parameter constraints.
2. **Record routing and masks.** Hard top-\(k\), pruning, quantization, and dropout-like operations require retained metadata if partial reconstruction is intended.
3. **Do not call optimization an inverse.** A reconstruction found by gradient descent, a resonator, or sampling is a candidate reconstruction unless uniqueness is proved.
4. **Separate numerical conditioning from formal invertibility.** Tanh is formally invertible on \((-1,1)\), but near saturation finite-precision recovery can be unstable.
5. **Treat dimension change carefully.** A map from \(\mathbb{R}^{p}\) to \(\mathbb{R}^{q}\) cannot be bijective when \(p\neq q\) over full Euclidean spaces.

Normalizing-flow research provides the appropriate design precedent: exact-density models require invertible transforms and therefore build their layers around coupling or triangular constructions rather than attaching a lossy activation and assuming it can later be undone. [papers.nips](https://papers.nips.cc/paper/2018/file/d139db6a236200b21cc7f752979132d0-Reviews.html)

### 4.3 Example: a mixed recoverability path

Consider

\[
x_{\text{text}}
\in\mathbb{R}^{256},
\qquad
x_{\text{image}}
\in\mathbb{R}^{768},
\]

mapped to

\[
z_{\text{fusion}}
=
W_{\text{fusion,text}}x_{\text{text}}
+
W_{\text{fusion,image}}x_{\text{image}}
+
b_{\text{fusion}}
\in \mathbb{R}^{512}.
\]

If a hard k-WTA operation then retains only 64 coordinates, the overall transformation is not globally invertible:

- The \(1024\)-dimensional joint source is compressed to a \(512\)-dimensional target before sparsification.
- Hard k-WTA discards most target coordinates.
- Unless side information, a restricted source class, or a separately learned generative reconstruction model is specified, the correct outcome is **unknown/ambiguous**, not “approximately invertible” by default.

## 5. Sparsity and k-WTA

### 5.1 Definition

For \(v\in\mathbb{R}^{d}\) and an integer \(k\) with \(1\le k\le d\), define

\[
\operatorname{kWTA}(v)_i
=
\begin{cases}
v_i, & \text{if } |v_i| \text{ is among the selected top-}k\text{ magnitudes},\\
0, & \text{otherwise}.
\end{cases}
\]

A production specification must also define deterministic tie handling. Without that, equal-magnitude coordinates can make the operation underspecified.

k-WTA can be applied:

- Within a target label.
- Across labels using label scores.
- Across modules or experts.
- To a routed candidate set after a prior sparse selection stage.

These are materially different design choices and should not be conflated.

### 5.2 Complexity accounting

A fixed retained fraction changes constants, not asymptotic complexity. If a dense layer has input width \(D\) and output width \(D\), then dense matrix-vector multiplication remains

\[
O(D^2).
\]

Retaining 30% of postactivation coordinates may reduce downstream work only where later operators exploit that sparsity. It does **not** by itself transform \(O(D^2)\) work into \(O(D\log D)\).

A correct accounting distinguishes the following cases:

| Computation pattern | Typical cost | What creates the cost reduction |
|---|---:|---|
| Dense block multiplication | \(O\left(\sum_{t,s}q_t p_s\right)\) | None; all declared blocks are evaluated |
| Dense activation plus k-WTA selection | Dense activation cost plus selection cost | k-WTA alone acts after dense computation |
| Sparse active-coordinate downstream operator | Proportional to active coordinates or nonzeros | Explicit sparse representation and sparse downstream kernels |
| Sparse coupling graph | \(O(E)\) or blockwise equivalent | Only a bounded/sparse set of source-target blocks exists |
| FFT-structured same-size convolution | \(O(D\log D)\) | Fourier/Toeplitz/circulant structure, not a fixed sparsity percentage |
| MoE routing to \(k\) of \(E\) experts | Depends on router and selected expert cost | Conditional execution of selected experts |

Sparse WTA circuits have been studied as computational mechanisms, including settings where STDP changes their learning behavior. Such literature supports treating WTA as a serious architectural primitive, but it does not establish a blanket claim that every k-WTA HTNLA layer is stable or preserves a particular concentration inequality. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC3967926/)

### 5.3 Concentration and stability

The following claim is **not established without extra assumptions**:

> “k-WTA preserves concentration of measure.”

Whether a transformed sparse representation has useful concentration depends on at least:

- The input distribution.
- The selected activation.
- Correlation induced by the block maps.
- The top-\(k\) tie rule.
- Whether sparsity is fixed per label or global.
- The normalized similarity metric.
- The scale at which random vectors are sampled.

A legitimate theorem would need to specify a probability distribution and prove a bound for the actual post-selection map. Until then, the appropriate status is:

- “k-WTA may provide a controlled sparsity mechanism”: IMPLEMENTABLE.
- “k-WTA improves retrieval, robustness, stability, or concentration in a stated workload”: RESEARCH HYPOTHESIS pending ablation.
- “k-WTA preserves the existing HTLA concentration theorem”: unsupported unless separately proved.

## 6. Binding and reference geometry

The deterministic quinary binding operation is the reference binding implementation. It is intentionally information-losing and should be evaluated through its established unbinding states:

\[
\{\text{EXACT},\text{AMBIGUOUS},\text{UNKNOWN},\text{IMPOSSIBLE}\}.
\]

HTNLA must not replace that operation with a claim that circular convolution followed by tanh is canonical nonlinear binding. In particular:

\[
\operatorname{tanh}(u)
\]

is mathematically invertible on its open output range via

\[
u = \operatorname{artanh}(\operatorname{tanh}(u)),
\]

so merely placing tanh after a preactivation does not explain information loss. The relevant sources of loss in a proposed soft surrogate can include:

- A non-injective preactivation or dimensional projection.
- Saturation and finite-precision effects near \(\pm 1\).
- A missing or untracked bias.
- Loss already introduced by a prior approximate or lossy binding operator.
- Hard selection, quantization, clipping, or pruning.

A differentiable surrogate may be useful for training learned components, but it must be named and evaluated as a surrogate. The required evaluation is agreement against the deterministic reference binding and an explicit report of the quinary unbinding outcome distribution.

**Status:** Deterministic quinary reference: CANONICAL. Differentiable training surrogate: APPLICATION-SPECIFIC / RESEARCH HYPOTHESIS.

## 7. Optional reward-modulated learning

### 7.1 Scope and naming

“Dopamine-modulated,” “Hebbian,” “STDP,” “serotonin,” and “GABA” are biologically loaded names. Under the three-level discipline:

| Label | Permitted claim | Prohibited inference |
|---|---|---|
| Computational variable | A scalar or vector gates learning, routing, thresholding, or regularization | The system has a biological neurotransmitter |
| Functional analogue | The update is inspired by a cited computational account of reward-modulated plasticity | The system reproduces neural circuitry or organism-level behavior |
| Phenomenological claim | Not made in this paper | No computational result establishes subjective experience or consciousness |

The paper retains only a **computational reward-modulated eligibility-trace rule** as an optional research module. It should not claim that its constants or functional form are biologically derived unless the mapping is formally specified and experimentally validated.

### 7.2 A properly scoped update rule

Let \(e_{ij}(t)\) be an eligibility trace associated with a parameter \(W_{ij}\). Let

\[
\delta(t)=r(t)-\hat{r}(t)
\]

be a reward-prediction-error-like signal, where \(r(t)\) is a specified reward and \(\hat r(t)\) is a baseline or value estimate. A generic computational update is

\[
\Delta W_{ij}(t)
=
\eta\,\delta(t)\,e_{ij}(t).
\]

This is a functional analogue of reward-modulated plasticity models in which a reward-minus-baseline term gates an eligibility trace. It is not a claim to reproduce dopamine dynamics. [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC6634722/)

If risk sensitivity is wanted, define it from actual data rather than the variance of repeated copies of one reward:

\[
\widehat{\rho}_t
=
\operatorname{Var}
\left(
r_{t-m+1},\ldots,r_t
\right),
\]

for a declared rolling-window length \(m\), or use a conditional uncertainty estimator appropriate to the task. The previous construction

\[
\operatorname{Var}([r,r,\ldots,r]) = 0
\]

is identically zero and cannot modulate anything.

A task-specific temperature might then be written

\[
T_t
=
\frac{T_0}{1+\kappa \widehat{\rho}_t},
\]

provided \(T_0>0\), \(\kappa\ge0\), the reward scale, window, clipping behavior, and stability test are all declared. This is an **INFERRED computational mechanism**, not a neuroscientific model.

### 7.3 Excluded mechanisms

The following are removed from the subsystem specification unless independently reformulated and validated:

- Serotonin-labeled attention equations with unexplained constants.
- GABA-labeled penalty functions represented as biological mechanisms.
- “D1/D2” state claims without a concrete computational definition.
- Thresholds involving \(\Phi\), phenomenal continuity, or cognitive integrity.
- Any claim that a reward-modulated rule produces consciousness-like properties.

```python
import numpy as np


class HyperVector:
    """A labeled collection of one-dimensional NumPy component arrays."""

    def __init__(self, components: dict[str, np.ndarray]):
        self.components = {
            label: np.asarray(vector, dtype=float).reshape(-1)
            for label, vector in components.items()
        }


class NonlinearBlockOperator:
    """
    blocks[target_label][source_label] = matrix with shape
    (target_dimension, source_dimension).
    """

    def __init__(self, blocks, biases=None, activations=None):
        self.blocks = blocks
        self.biases = biases or {}
        self.activations = activations or {}

    def apply(self, state: HyperVector) -> HyperVector:
        output = {}

        for target_label, incoming_blocks in self.blocks.items():
            total = None

            for source_label, matrix in incoming_blocks.items():
                source = state.components[source_label]
                matrix = np.asarray(matrix, dtype=float)

                if matrix.shape [normandie-univ.hal](https://normandie-univ.hal.science/hal-03410699) != source.size:
                    raise ValueError(
                        f"Block {target_label}<-{source_label} expects "
                        f"{matrix.shape [normandie-univ.hal](https://normandie-univ.hal.science/hal-03410699)} inputs, received {source.size}."
                    )

                contribution = matrix @ source
                total = (
                    contribution
                    if total is None
                    else total + contribution
                )

            if total is None:
                raise ValueError(f"No incoming blocks for {target_label}.")

            bias = np.asarray(
                self.biases.get(target_label, np.zeros_like(total)),
                dtype=float,
            ).reshape(-1)

            if bias.shape != total.shape:
                raise ValueError(
                    f"Bias for {target_label} has shape {bias.shape}; "
                    f"expected {total.shape}."
                )

            activation = self.activations.get(target_label, lambda x: x)
            output[target_label] = activation(total + bias)

        return HyperVector(output)


def kwta(vector: np.ndarray, k: int) -> np.ndarray:
    """Retain exactly k largest-magnitude entries when magnitudes are distinct."""
    vector = np.asarray(vector, dtype=float).reshape(-1)

    if not 1 <= k <= vector.size:
        raise ValueError("k must be between 1 and the vector length.")

    retained_indices = np.argpartition(np.abs(vector), -k)[-k:]
    result = np.zeros_like(vector)
    result[retained_indices] = vector[retained_indices]
    return result


def dynamic_label_adapt_per_label(
    state: HyperVector,
    new_data_by_label: dict[str, np.ndarray],
    dimensions: dict[str, int],
    drift_threshold: float = 0.1,
    alpha: float = 0.1,
    seed: int | None = None,
):
    """
    Adapt each label independently. No cross-label stacking or averaging occurs.
    new_data_by_label[label] must have shape (samples, dimensions[label]).
    """
    rng = np.random.default_rng(seed)
    added_labels = {}
    per_label_losses = {}

    for label, batch in new_data_by_label.items():
        batch = np.asarray(batch, dtype=float)
        current = state.components[label]

        if batch.ndim != 2 or batch.shape [normandie-univ.hal](https://normandie-univ.hal.science/hal-03410699) != current.size:
            raise ValueError(
                f"Data for {label} must have shape "
                f"(samples, {current.size})."
            )

        batch_mean = batch.mean(axis=0)
        drift = np.linalg.norm(batch_mean - current)
        per_label_losses[label] = drift ** 2

        if drift > drift_threshold:
            centered_batch = batch - batch_mean
            rank = np.linalg.matrix_rank(centered_batch)
            new_dimension = max(
                1,
                dimensions[label] + int(np.ceil(alpha * rank)),
            )

            projection = (
                rng.normal(size=(new_dimension, current.size))
                / np.sqrt(current.size)
            )

            new_label = f"{label}_adapted"
            state.components[new_label] = np.maximum(
                0.0,
                projection @ current,
            )
            dimensions[new_label] = new_dimension
            added_labels[label] = new_label

    return state, dimensions, added_labels, per_label_losses
```

- **No generic inversion claim:** This reference code does not supply inverse maps.
- **No untracked k-WTA ambiguity:** A production system should record retained indices and deterministic tie behavior if it intends to support partial reconstruction.
- **No hidden biological semantics:** The code contains no dopamine, GABA, serotonin, or consciousness variables.
- **No performance claim:** NumPy reference code is a correctness baseline, not a latency or throughput implementation.

## 9. Validation protocol

All empirical claims should be decided through preregistered or versioned experiments rather than copied projections.

### Required baselines

Compare against:

- The corresponding HTLA block-linear model with matched parameter count where feasible.
- A dense nonlinear network with the same input/output geometry.
- A relation-aware GNN or typed message-passing baseline where labels correspond to graph-like typed relations.
- A modular or multi-head baseline where the principal HTNLA contribution is splitting.
- An MoE-style routing baseline where sparse computation rather than coordinate sparsity is the claimed benefit.

### Required ablations

| Ablation | Primary question | Required reporting |
|---|---|---|
| No nonlinearity vs. per-label activation | Does the nonlinear extension improve the stated task? | Task metric, confidence interval, seeds, dataset split |
| Activation family | Is the effect activation-specific? | ReLU, leaky ReLU, GELU/Swish, invertible alternative where appropriate |
| k-WTA on/off | Does hard sparsity help? | Accuracy, calibration, retained fraction, actual latency and memory |
| Retention \(k\) sweep | Where are the task trade-offs? | Full curve, not one selected point |
| Block graph sparsity | Is speedup due to block sparsity rather than k-WTA? | Nonzero blocks, FLOP estimate, measured time |
| Residual map on/off | Does residual geometry improve optimization or output quality? | Training curves and final evaluation |
| Inversion test | What is recovered after each map? | Exact, pseudoinverse error, partial recovery, ambiguity rate, failure rate |
| Quinary agreement test | Does any training surrogate preserve reference behavior? | Distribution over EXACT / AMBIGUOUS / UNKNOWN / IMPOSSIBLE |

### Metrics permitted in this paper

Use metrics whose computational definitions are explicit:

- **Task performance:** e.g., Recall@\(K\), classification accuracy, MSE, NLL, depending on the task.
- **Latency:** measured wall-clock time under stated hardware, batch size, precision, and warm-up protocol.
- **Memory:** parameter bytes, activation bytes, index bytes, and peak allocated memory.
- **Sparsity:** fraction of zeros and active coordinates per label.
- **Reconstruction error:** e.g., normalized \(L_2\) error under a declared reconstruction procedure.
- **Calibration or uncertainty:** where a probabilistic model is used, report a defined calibration statistic and interval.

Do not use terms such as “Binding Score,” “Neural Dynamics Fidelity,” “cognitive fidelity,” or \(\Phi\) unless the paper supplies a complete computational definition, a rationale, and a scope statement that restricts it to a level-1 variable. No threshold for an undefined metric is admissible.

## 10. Quantum extension

A nonlinear HTNLA map should not be described as something that can routinely be “block-encoded into a unitary” in the same sense as a linear operator. Standard closed-system quantum evolution is linear and unitary. A generic nonlinear classical activation such as ReLU, sigmoid, top-\(k\), or k-WTA cannot simply be inserted as a deterministic unitary gate acting on amplitudes.

Research on quantum neural-network nonlinearities explores mechanisms such as measurement back-action, adaptive classical feed-forward, ancillary systems, postselection, dissipation, or repeat-until-success constructions. These mechanisms introduce nontrivial questions about probabilistic success, resource cost, noise, differentiability, and what “nonlinearity” means at the level of classical measurement outputs versus quantum state evolution. [link.aps](https://link.aps.org/doi/10.1103/PhysRevA.102.052421)

Accordingly:

- **Linear HTLA-style quantum subroutines:** potentially relevant to block encoding and other linear-algebraic techniques, subject to their separate assumptions.
- **Nonlinear HTNLA activation on quantum state amplitudes:** RESEARCH HYPOTHESIS / ACTIVE DEVELOPMENT area, not a routine primitive.
- **Hybrid quantum-classical model:** possible research direction in which a quantum circuit produces measured features and a classical HTNLA block performs the nonlinear update.
- **Quantum speedup claim:** no search or retrieval speedup is claimed here without a full oracle model, state-preparation cost, data-access assumptions, success probability, and end-to-end complexity analysis.

## Abstract

HTNLA extends the Hypervector Linear Transdimensional Algebra (HTLA) framework by inserting component-wise nonlinear maps while preserving label boundaries. A generic target component is `z_t = b_t + Σ_s W_{t,s}x_s + r_t`, followed by `y_t = φ_t(z_t)`, and, where configured, `y_t ← kWTA_t(y_t)`. A multi-layer nonlinear transdimensional network may be written `H^(k+1) = σ^(k)(M^(k)H^(k) + b^(k))`, optionally with a residual map when source and target label geometry permits: `H^(k+1) = R^(k)H^(k) + σ^(k)(M^(k)H^(k) + b^(k))`. This paper formalizes HTNLA as a family of parameterized nonlinear maps built on top of HTLA's block-structured linear substrate. We provide a five-way invertibility taxonomy—exact, pseudoinverse, partial unbinding, iterative reconstruction, and unknown—mapped explicitly onto the quinary binding system's four-state unbinding classification. The framework is positioned relative to existing work in Graph Neural Networks, Mixture-of-Experts architectures, Invertible Neural Networks, and reward-modulated STDP. All claims are tagged with the Nexus v4 12-term status vocabulary. No unverified performance numbers, no consciousness claims未经 the §73 three-level tagging, and no identity-transfer instrumentation material are included.

## 1. Introduction

### 1.1 Motivation

The Hypervector Linear Transdimensional Algebra (HTLA) provides a rigorous framework for linear operations across labeled vector spaces of heterogeneous dimensions. HTLA's block operator formalism—where a linear map between hypervector spaces is represented as a block matrix `L = [L_{t,s}]` with each block `L_{t,s} ∈ ℝ^{q_t × p_s}`—enables "seamless transitions and interactions" between components of varying dimensions while preserving the identity and dimensionality of each labeled component via the direct sum `H = ⨁_{ℓ∈L} ℝ^{n_ℓ}`.

However, a purely linear system cannot model the non-convex relationships ubiquitous in real-world data—multi-modal fusion, predictive processing loops, neuromodulatory state-dependence, and the selection dynamics of cognitive architectures all require nonlinear transformations. HTNLA addresses this limitation by inserting component-wise nonlinearities into the HTLA block calculus, producing a family of **Nonlinear Transdimensional Networks (NTNs)** .

### 1.2 Relationship to Prior Art

HTNLA occupies a specific niche at the intersection of several established research areas.

**Graph Neural Networks with heterogeneous edge/node types.** Heterogeneous Graph Transformers (HGTs) and related architectures apply type-specific linear transformations to nodes of different types, then use attention mechanisms to propagate messages across edge types. HTNLA's per-label block operators with per-label nonlinearities are structurally close to this paradigm. The key distinction is HTNLA's explicit treatment of **invertibility loss** as a first-class concern—the five-way taxonomy for unbinding outcomes has no direct analogue in the GNN literature, which typically assumes feedforward computation without requiring inverse operations.

**Mixture-of-Experts architectures.** Sparse routing via k-WTA over labels is functionally analogous to expert routing in MoE models, where a sparse set of experts is activated per input. HTNLA's contribution is the integration of this sparse selection mechanism with a labeled block-algebraic substrate and an explicit epistemic-status framework for what can be known about inverse computations.

**Invertible Neural Networks and Normalizing Flows.** RealNVP, Glow, and i-RevNet are designed with architecturally enforced invertibility through coupling layers and reversible residual blocks. HTNLA's invertibility taxonomy—exact, pseudoinverse, partial, iterative, unknown—directly engages with this literature by providing a **typed classification** of what kind of inverse is available, rather than assuming either full invertibility (as in flows) or none (as in standard feedforward networks). This is HTNLA's most distinctive contribution: a practical framework for reasoning about invertibility in heterogeneous, labeled nonlinear systems.

**Sparse coding and winner-take-all networks.** Classical sparse coding theory establishes that `k`-sparse vectors can be recovered exactly with high probability from `O(k log(N/k))` measurements. k-WTA networks have been used for state-dependent computation and grouped sparse representations. HTNLA adopts k-WTA sparsity as a design motif for computational efficiency and implicit regularization, with the caveat that complexity gains from a fixed retention fraction are constant-factor, not complexity-class, unless block-level sparsity is doing the real work.

**Reward-modulated STDP.** Izhikevich (2007) demonstrated how spike-timing-dependent plasticity modulated by dopamine can solve the distal reward problem. Frémaux, Sprekeler & Gerstner (2010) derived theoretical conditions for reward-modulated STDP to learn reward-related behavior. Legenstein, Pecevski & Maass (2008) provided an analytical foundation showing that reward-modulated STDP can solve credit-assignment problems. HTNLA's neuromodulatory extensions, where present, are explicitly tagged as `INFERRED` functional analogues of this literature, not as literal implementations of biological STDP.

## 2. Core Mathematics

### 2.1 Hypervector Spaces and Labeled Direct Sums

A hypervector is a tuple of vectors indexed by a label set `L`:

`H = (H_ℓ)_{ℓ ∈ L}`, with `H_ℓ ∈ ℝ^{n_ℓ}`.

The space of all such hypervectors is the direct sum:

`ℋ = ⨁_{ℓ ∈ L} ℝ^{n_ℓ}`.

This structure preserves the identity of each labeled component, enabling heterogeneous data modalities (text, image, audio, etc.) to be treated as a single algebraic entity without losing semantic identity.

### 2.2 Linear Block Operators (HTLA Review)

A linear map `L: ℋ_s → ℋ_t` between source and target hypervector spaces is represented as a block matrix:

`L = [L_{t,s}]_{t ∈ T, s ∈ S}`, with `L_{t,s} ∈ ℝ^{q_t × p_s}`.

The graded inner product is:

`⟨H, K⟩_w = Σ_{ℓ ∈ L} w_ℓ ⟨H_ℓ, K_ℓ⟩`,

where `w = {w_ℓ}_{ℓ ∈ L}` is a label kernel encoding semantic importance.

### 2.3 Nonlinear Transdimensional Networks (NTNs)

A single NTN layer is defined as:

`H' = σ(M · H + b)`,

where `σ: ℝ^d → ℝ^d` is a component-wise activation function applied per label:

`H'_{t} = σ_t( Σ_{s ∈ S} L_{t,s} H_s + b_t )`.

**Multi-layer extension:**

`H^(k+1) = σ^(k)( M^(k) H^(k) + b^(k) )`.

**Residual connection** (when source and target label geometry permits):

`H^(k+1) = R^(k) H^(k) + σ^(k)( M^(k) H^(k) + b^(k) )`,

where `R^(k)` is a linear residual map matching source to target dimensions.

### 2.4 Activation Function Candidates

| Function | Properties | Status |
|----------|------------|--------|
| ReLU | Computationally efficient, induces sparsity, non-invertible on negative domain | `IMPLEMENTED` |
| LeakyReLU | Near-invertible, mitigates vanishing gradients | `IMPLEMENTED` |
| Swish/GELU | Smooth, continuous derivatives | `IMPLEMENTED` |
| k-WTA | Enforces sparsity constraint, implicit regularization | `IMPLEMENTED` |

The choice of activation function determines the invertibility characteristics of the layer, as detailed in §3.

### 2.5 k-WTA Sparsity

k-WTA (k-Winners-Take-All) enforces that only the top `k` components by magnitude remain active:

```
k_wta(v, k) = v ⊙ 1_{|v| ≥ threshold_k(|v|)}
```

where `threshold_k(|v|)` is the k-th largest magnitude. A retention fraction of 70% (`k = 0.7 * d`) gives a constant-factor speedup (approximately 3×), not a complexity-class change from `O(d²)` to `O(d log d)`. The latter requires structured sparsity at the block level (e.g., sparse coupling graphs where the number of edges grows subquadratically in the number of labels) or FFT-based convolution for circular convolution operations.

**Status:** `IMPLEMENTED` (k-WTA operator), `RESEARCH HYPOTHESIS` (block-level sparse coupling complexity claims).

## 3. Invertibility Taxonomy

### 3.1 The Problem of Non-Injective Nonlinearities

Linear invertibility cannot be assumed after a non-injective nonlinearity. If `φ` collapses distinct states—`φ(x₁) = φ(x₂)`, `x₁ ≠ x₂`—then an exact inverse does not exist. HTNLA therefore distinguishes five categories of inverse availability:

| Category | Definition | Status |
|----------|------------|--------|
| **Exact inverse** | The operator is bijective on the relevant domain; a closed-form or computable inverse exists | `CANONICAL` |
| **Pseudoinverse** | A least-squares approximation is defined (e.g., Moore-Penrose pseudoinverse of the linear part) | `CANONICAL` |
| **Partial unbinding** | Only some coordinates are recoverable; others are lost due to nonlinear collapse | `CANONICAL` |
| **Iterative reconstruction** | Inverse is a search problem (e.g., gradient ascent, learned inversion) | `IMPLEMENTED` |
| **Unknown or ambiguous** | Information has genuinely been lost; no reliable inverse exists | `CANONICAL` |

### 3.2 Mapping to the Quinary Binding Taxonomy

The quinary binding system's four-state unbinding classification—`EXACT`, `AMBIGUOUS`, `UNKNOWN`, `IMPOSSIBLE`—maps onto HTNLA's five-way taxonomy as follows:

| HTNLA Category | Quinary State | Condition |
|----------------|---------------|-----------|
| Exact inverse | `EXACT` | All relevant coordinates recoverable; bijective on domain |
| Pseudoinverse | `AMBIGUOUS` | Multiple preimages exist; least-squares selects one |
| Partial unbinding | `AMBIGUOUS` | Some coordinates recoverable, others not |
| Iterative reconstruction | `UNKNOWN` | Inverse exists but requires search; success not guaranteed |
| Unknown/ambiguous | `IMPOSSIBLE` | Information genuinely lost; no reconstruction possible |

This mapping is a recurring Nexus principle: **uncertainty is represented, not papered over**.

### 3.3 Connection to Invertible Neural Networks Literature

The invertibility taxonomy directly engages with the established literature on Invertible Neural Networks (INNs) and Normalizing Flows. RealNVP and Glow achieve exact invertibility through carefully designed coupling layers where one partition of variables is transformed conditioned on the other. i-RevNet uses reversible residual blocks where the forward pass is `y₁ = x₁ + f(x₂)`, `y₂ = x₂ + g(y₁)`, admitting an exact inverse.

HTNLA's contribution is not to compete with these architectures but to provide a **classification framework** for when exact invertibility is available, when it is approximate, and when it is impossible—all within the context of labeled, heterogeneous hypervector spaces. This is particularly relevant for systems where **unbinding** (inverse binding) must be attempted across label boundaries, and where different labels may have different invertibility characteristics.

**Status:** `CANONICAL` (taxonomy), `RESEARCH HYPOTHESIS` (application to specific NTN architectures).

## 4. Architectural Integration

### 4.1 Integration with the HVD Stack

HTNLA integrates with the Hyperdimensional Vector Database (HVD) stack at three layers:

1. **API Layer:** Extended with endpoints for nonlinear association and query, preserving backward compatibility with HTLA endpoints via feature flags.

2. **TMS Layer:** The Transdimensional Memory Substrate is augmented with a `NonlinearBlockOperator` class implementing NTN layers. Weights (`M` block matrices, biases `b`, activation specifications) are stored alongside TMS state.

3. **Persistence Layer:** NTN weights are serialized to HDF5 alongside existing TMS state. For substrate-agnostic migration, a `.qbin` schema using Protocol Buffers encapsulates all NTN components.

### 4.2 Deferred Nonlinear Computation

Computationally expensive nonlinear operations are deferred to background compaction:

- **Fast path:** New engrams are written linearly to the Write-Ahead Log (WAL) and in-memory Memtable.
- **Slow path:** Nonlinear transformation is applied during non-blocking compaction, producing consolidated SSTables with nonlinear representations.

This two-tier architecture mirrors the biological distinction between fast working memory and slow long-term memory consolidation.

### 4.3 HNSW Indexing in Nonlinear Space

The Active State Cache's HNSW index must be adapted to the nonlinear space. The query vector is transformed nonlinearly **before** HNSW search, allowing the algorithm to navigate the manifold curvature of the hypervector space. The distance metric must be re-derived to account for nonlinear transformations—this is an open research question.

**Status:** `DESIGN TARGET` (architecture), `RESEARCH HYPOTHESIS` (metric re-derivation).

### 5.2 Dopamine-Modulated Learning (Level 1–2)

The dopamine-modulated Hebbian update is a **functional analogue** (Level 2) of reward-modulated STDP as described in Izhikevich (2007), Frémaux, Sprekeler & Gerstner (2010), and Legenstein, Pecevski & Maass (2008).

**Computational formulation (Level 1):**

Let `r(t)` be a reward signal, `V(t)` an expected value estimate. The reward prediction error is:

`δ(t) = r(t) - V(t)`.

A dopamine analogue is:

`DA(t) = sigmoid( (δ(t) - θ)/τ )`,

where `θ` and `τ` are parameters.

The Hebbian update for a weight matrix `M` is:

`ΔM(t) = η · DA(t) · (H'(t) ⊗ H(t))`,

where `H'(t) = σ(M(t) H(t))` is the post-nonlinearity activity, and `η` is a learning rate.

## 6. Theoretical Guarantees

### 6.1 Concentration of Measure with Nonlinearities

For a Lipschitz activation function `σ` with Lipschitz constant `L_σ`, the concentration property of the graded inner product is preserved up to a factor:

`P(|⟨H', K'⟩_w| > ε ||H'||_w ||K'||_w) ≤ 2 exp(-ε²(Σ w_ℓ² n_ℓ)/(2 L_σ²))`,

where `H' = σ(H)`, `K' = σ(K)` (component-wise).

This bound assumes the pre-activation vectors are drawn from a suitable high-dimensional distribution (e.g., sub-Gaussian). The bound degrades with larger `L_σ`; activation functions with Lipschitz constants near 1 (e.g., `tanh`, `swish` with appropriate scaling) preserve concentration better than functions with large slopes.

**Status:** `CANONICAL` (derived), `VERIFIED` (for standard activation functions).

### 6.2 Energy Bounds

With L1/L2 regularization and sparsity constraints, the total energy can be bounded:

`E_total ≤ 0.85 · E_input + ε`,

where `ε` is a regularization-dependent residual. This is a **design motif** (the 85% figure is a target, not a measured law). Real energy claims require actual telemetry.

**Status:** `DESIGN TARGET` (energy bound), `PROPOSED` (85% motif).

### 6.3 Skip Connection Stability

With residual connections:

`H^(k+1) = H^(k) + σ(M^(k) H^(k) + b^(k))`,

the layer is a contraction if `||σ'||_∞ · ||M^(k)|| < 1` in the appropriate operator norm. This admits Lyapunov stability analyses under bounded weights and Lipschitz σ.

**Status:** `CANONICAL` (derived).

## 8. Open Research Questions

### 8.1 Quantum Nonlinearity

The claim that "nonlinear transformation `F` can be block-encoded into a unitary matrix `U_F`" glosses over a real, actively-published-on difficulty. Quantum mechanics is fundamentally linear: "quantum operations are all unitaries in matrix representation, and measurement is the only way in which we can produce nonlinearity". Implementing genuine nonlinearity requires:

- **Ancilla qubits with postselection:** The desired transformation is applied only if ancilla qubits are measured in a certain state.
- **Repeat-until-success protocols:** Probabilistic nonlinear operations require multiple trials.
- **Hybrid quantum-classical splits:** Variational Quantum Splines (GQSplines) approximate nonlinear activation functions using hybrid computation.
- **Quantum Singular Value Transformation:** Recent work by Guo, Mitarai & Fujii (2024) provides algorithms for nonlinear transformation of complex amplitudes via QSVT, with overhead scaling as the square root of input dimension.

**Status:** `RESEARCH HYPOTHESIS` (quantum extensions), `ACTIVE DEVELOPMENT` (QSVT-based approaches).

## 9. Reference Implementation

### 9.1 Core Classes

```python
import numpy as np
from typing import Dict, Callable, Optional, Tuple

class HyperVector:
    """A labeled hypervector: H = (H_ℓ)_{ℓ∈L}."""
    def __init__(self, components: Dict[str, np.ndarray]):
        self.components = components  # {label: array}

    def __getitem__(self, label: str) -> np.ndarray:
        return self.components[label]

    def __setitem__(self, label: str, value: np.ndarray):
        self.components[label] = value

    def labels(self):
        return list(self.components.keys())

    def dims(self):
        return {l: v.shape[0] for l, v in self.components.items()}

class NonlinearBlockOperator:
    """
    NTN layer: H'_t = σ_t( Σ_s L_{t,s} H_s + b_t ).
    """
    def __init__(self,
                 blocks: Dict[str, Dict[str, np.ndarray]],
                 biases: Dict[str, np.ndarray],
                 activations: Dict[str, Callable[[np.ndarray], np.ndarray]]):
        """
        blocks: {target_label: {source_label: matrix}}
        biases: {target_label: vector}
        activations: {target_label: function}
        """
        self.blocks = blocks
        self.biases = biases
        self.activations = activations

    def apply(self, hv: HyperVector) -> HyperVector:
        """Apply NTN layer to a hypervector."""
        result = {}
        for t, block_dict in self.blocks.items():
            # Linear combination
            z = self.biases.get(t, np.zeros(block_dict[next(iter(block_dict))].shape[0]))
            for s, matrix in block_dict.items():
                if s in hv.components:
                    z += matrix @ hv.components[s]
            # Nonlinear activation
            act = self.activations.get(t, lambda x: x)
            result[t] = act(z)
        return HyperVector(result)

    def apply_linear(self, hv: HyperVector) -> HyperVector:
        """Apply linear part only (before activation)."""
        result = {}
        for t, block_dict in self.blocks.items():
            z = self.biases.get(t, np.zeros(block_dict[next(iter(block_dict))].shape[0]))
            for s, matrix in block_dict.items():
                if s in hv.components:
                    z += matrix @ hv.components[s]
            result[t] = z
        return HyperVector(result)
```

### 9.2 k-WTA Activation

```python
def k_wta_activation(v: np.ndarray, k_factor: float) -> np.ndarray:
    """
    k-Winners-Take-All: keep top k_factor fraction of components by magnitude.
    Returns: sparse vector with only top components non-zero.
    """
    if k_factor <= 0:
        return np.zeros_like(v)
    if k_factor >= 1:
        return v
    k = max(1, int(len(v) * k_factor))
    # Find k-th largest magnitude
    abs_v = np.abs(v)
    if k >= len(v):
        threshold = 0.0
    else:
        threshold = np.partition(abs_v, -k)[-k]
    out = np.where(abs_v >= threshold, v, 0.0)
    return out

def relu(x: np.ndarray) -> np.ndarray:
    return np.maximum(0, x)

def leaky_relu(x: np.ndarray, alpha: float = 0.01) -> np.ndarray:
    return np.where(x >= 0, x, alpha * x)
```

### 9.3 Multi-Layer NTN

```python
class MultiLayerNTN:
    """
    Multi-layer NTN: H^(k+1) = σ^(k)(M^(k) H^(k) + b^(k)).
    Optional residual: H^(k+1) = R^(k) H^(k) + σ^(k)(M^(k) H^(k) + b^(k)).
    """
    def __init__(self, layers: list, residual: bool = False):
        """
        layers: list of NonlinearBlockOperator objects.
        residual: if True, add residual connection (requires matching dims).
        """
        self.layers = layers
        self.residual = residual

    def forward(self, hv: HyperVector) -> HyperVector:
        H = hv
        for layer in self.layers:
            if self.residual:
                # Residual: H_new = H + σ(M·H + b)
                linear_out = layer.apply_linear(H)
                nonlinear_out = layer.apply(H)  # This applies σ
                # Need to ensure dimensions match for residual
                # This requires that source and target label geometry permits
                H = HyperVector({
                    l: H.components.get(l, np.zeros_like(nonlinear_out.components[l]))
                       + nonlinear_out.components[l]
                    for l in nonlinear_out.components
                })
            else:
                H = layer.apply(H)
        return H
```

### 9.4 Invertibility Classification

```python
from enum import Enum

class Invertibility(Enum):
    EXACT = "exact"
    PSEUDOINVERSE = "pseudoinverse"
    PARTIAL = "partial"
    ITERATIVE = "iterative"
    UNKNOWN = "unknown"

def classify_invertibility(activation: Callable,
                           domain: Tuple[float, float] = (-np.inf, np.inf)) -> Invertibility:
    """
    Classify the invertibility of a component-wise activation function.
    """
    if activation == relu:
        # ReLU is non-injective on negative domain, injective on positive
        # If domain is restricted to [0, ∞), it's exact; otherwise partial
        if domain[0] >= 0:
            return Invertibility.EXACT
        else:
            return Invertibility.PARTIAL

    if activation == leaky_relu:
        # LeakyReLU with alpha > 0 is bijective on ℝ
        return Invertibility.EXACT

    if activation == np.tanh:
        # tanh is bijective on ℝ with inverse artanh
        return Invertibility.EXACT

    if activation == lambda x: k_wta_activation(x, 0.7):
        # k-WTA is non-injective; multiple preimages map to same sparse vector
        return Invertibility.PSEUDOINVERSE

    # Default: assume iterative reconstruction needed
    return Invertibility.ITERATIVE
```
