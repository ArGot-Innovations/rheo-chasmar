## 1. Open Research Question 1: Novelty Scoping and Prior Art

### 1.1 Named Tensor Notation (Chiang, Rush & Barak, 2023)

Chiang, Rush and Barak's *Named Tensor Notation* introduces a notation for tensors with named axes, making it easy to lift operations on low-order tensors to higher-order ones. The work emerged from the "Tensor Considered Harmful" line of critique, which argued that standard tensor implementations force "bad habits such as exposing private dimensions, broadcasting based on absolute position, and keeping type information in documentation".

**Crucial distinction:** Named Tensor Notation names axes *within* a tensor — it operates on a single tensor's dimensions (e.g., `batch`, `channel`, `height`, `width`). HTLA's construction is fundamentally different: it glues *genuinely heterogeneous-dimensional spaces* via direct sum over a label set L. Where NamedTensor lets you say "this axis is named 'batch'," HTLA lets you say "this *entire subspace* has label 'vision' and dimension 1024, this other subspace has label 'language' and dimension 512, and they live in the same direct-sum space." The former is axis labeling within a fixed-rank object; the latter is space labeling across objects of different ranks. NamedTensor's framework cannot represent a direct sum of spaces of different dimensionalities as a single composable object — it assumes a fixed tensor rank and shape.

### 1.2 Categorical Foundations of Deep Learning

Crescenzi's 2024 survey "Towards a Categorical Foundation of Deep Learning" covers recent work attempting to study machine learning categorically, focusing on categorical optics for gradient-based learning, categorical algebras linking computer science to neural networks, functors linking layers of abstraction, and string diagrams for neural network architectures.

The Peirce-decomposition/ringoid framing proposed for HTLA (fix #3) situates naturally within this active research program. Mitchell's "rings with several objects" (1972) provides the precise mathematical language: a ringoid (or preadditive category) is exactly the right structure for a collection of vector spaces indexed by labels with morphisms between them. This is not presented as sui generis but as a specific instance of a well-studied categorical structure being applied to the labeled-state setting.

### 1.3 Classical Direct-Sum / Block-Diagonal Representation Theory

The use of direct sums and block-diagonal operators is classical linear algebra. HTLA's contribution is the *label-aware* treatment: the explicit tracking of which label each block corresponds to, the epistemic status algebra layered on top, and the concrete quinary encoding. The mathematical tools themselves are standard; the assembly is the novelty.

### 1.4 Hyperdimensional Computing / Vector Symbolic Architecture

Kanerva (2009) introduced hyperdimensional computing as computing with high-dimensional random vectors, building on earlier work including Plate's Holographic Reduced Representations (2003), Spatter Code, and Semantic Vectors. Plate's HRRs use circular convolution and correlation for binding and unbinding.

**Key caveat:** The HDC/VSA literature has long recognized the invertibility limitations of binding operations. Plate's book explicitly discusses the need for "clean-up memories" to recover bound components. HTLA's quinary binding operation, with its four epistemic partial-unbind states (`EXACT / AMBIGUOUS / UNKNOWN / IMPOSSIBLE`), is consistent with this literature — it makes explicit what the HDC/VSA literature has long known implicitly: binding is not perfectly invertible, and the degree of recoverability depends on the structure of the representation. HTLA's contribution is *formalizing* this epistemic status algebra rather than assuming perfect unbinding.

### 1.5 Labeled-Array / Unit-Checked Scientific Computing

Loose engineering analogs exist in xarray (labeled multidimensional arrays) and pint/unyt (unit-checked quantities). These are useful analogies for one honest sentence but are not load-bearing claims — they lack the algebraic structure (direct sums, block operators, morphisms) that HTLA provides.

## 3. Open Research Question 3: Quantum Section Legitimacy

### 3.1 QSVT and Block Encoding Literature

The quantum singular value transformation (QSVT) framework, introduced by Gilyén, Su, Low and Wiebe (STOC 2019, arXiv:1806.01838), provides a systematic way to implement polynomial transformations of the singular values of a block-encoded matrix. Block encoding is the standard technique for representing a matrix A as the top-left block of a larger unitary. Sparse matrices can be block-encoded using various methods including the "dictionary data structure".

e_t\operatorname{End}(\mathcal H)e_s ,
\]
and the label-indexed block spaces can equivalently be regarded as a finite preadditive category—a “ring with several objects” in Mitchell’s terminology. Rings equipped with complete systems of orthogonal idempotents are classically represented by precisely this generalized matrix/Peirce structure. citeturn20search9turn14search0turn14search5

The categorical “faithful but not full” result described in the legacy draft should be deleted rather than repaired. Under the definition supplied in the rewrite specification—where the morphisms are already *all* linear maps between flattened spaces—the flattening map is full as well as faithful by definition. fileciteturn0file0 A sparse coupling graph could make a restricted-morphism category mathematically meaningful, but that additional structure should only be introduced if Nexus actually uses it as an operator constraint; it is unnecessary for the core HTLA paper.

The weighted-similarity section needs an equally sharp correction. For
\[
B_w(H,K)=\sum_{\ell\in L}w_\ell\langle H_\ell,K_\ell\rangle,
\]
strictly positive weights yield an inner product; nonnegative weights with at least one zero-weight component yield only a positive-semidefinite form and a seminorm on the full state space. For a general cross-label matrix \(W\), \(H^\top W K\) is an inner product exactly when \(W\) is symmetric positive definite; symmetric positive semidefiniteness without definiteness again gives a seminorm, while an asymmetric or indefinite \(W\) should be called a compatibility or similarity score. This follows directly from the defining positivity and symmetry axioms and closes the semantic gap identified in the supplied specification. fileciteturn0file0

The numerical correction in the specification is confirmed by executed code. For the stated Tikhonov problem, the regularized solution is

[0.694151134,\ 1.2716922229,\ 1.6352951979]^\top
\]
and the Euclidean residual is

The same result was independently obtained in the executed artifact from the singular-value formula and the regularized normal equations, with a maximum componentwise difference of \(8.8817841970012523\times10^{-16}\). The corrected implementation reverses the type direction of the pseudoinverse—old target labels become inverse source labels, and old source labels become inverse target labels—and uses ordered label sequences for position-dependent slicing. The literature review does **not** support a general \(O(\log |L|)\) gradient-cost theorem. Sparse mixture-of-experts work shows that conditional activation can make computation grow much more slowly than total parameter capacity and, under particular routing designs, keep per-example expert computation bounded while model capacity increases. It does not establish a generic logarithmic backward-pass complexity in the number of HTLA labels. citeturn16view1turn16view2 The claim should therefore disappear from the core mathematics. At most it can survive as `RESEARCH HYPOTHESIS`, with assumptions on coupling sparsity and routing cost and a falsification experiment that separately measures router, active-block, communication, and backward costs.

The heavy-tail concentration appendix likewise needs replacement, not cosmetic editing. Rudelson and Vershynin’s Hanson–Wright inequality has a quadratic-\(t\) Frobenius-norm regime and a **linear-\(t\)** operator-norm regime. citeturn17view0turn22academia0 Real extensions to \(\alpha\)-sub-exponential variables exist, but Götze, Sambale, and Sinulis derive multi-level bounds involving several matrix norms; the literature does not justify obtaining a heavy-tail theorem by simply changing the exponents in the sub-Gaussian two-term formula. citeturn16view5turn22academia2 The cleanest core paper should therefore state the standard Hanson–Wright theorem correctly and move any heavy-tail extension to a cited, theorem-specific appendix.

Quantum block encoding and persistent homology should also remain outside the working mathematics. Qubitization and quantum singular-value transformation are genuine generic operator tools, but the reviewed literature supplies no label- or Peirce-specific quantum advantage for HTLA. citeturn15view4turn18search1 Zigzag persistence genuinely addresses topology that changes through a sequence of spaces or complexes and could become relevant to a time-varying Nexus coupling graph, but a sparse quinary vector by itself does not specify the filtration or topological object required for such an analysis. citeturn15view6 Both belong behind a `RESEARCH HYPOTHESIS` boundary.

It refers to a current HTLA draft and a higher-rigor companion chapter, but those manuscripts are not contained in the material available for this analysis. fileciteturn0file0 Accordingly, this report can supply the replacement mathematical spine, source-backed dispositions, executed correction code, and claim audit, but it cannot certify that every sentence, theorem, self-citation, benchmark table, or speculative passage in the unseen manuscripts has been removed. ## Scope, architectural boundary, and research questions

The safe scope is narrower than a general theory of “dimension-agnostic machine learning.” HTLA can rigorously describe a finite family of labeled component spaces, linear transformations between them, similarity structures that respect their labels, dimension-changing linear maps with explicit distortion/recoverability statements, and low-rank compression of the resulting blocks. HTNLA begins where nonlinear maps enter. The Nexus-specific quinary representation and epistemic unbinding states should appear as an **application contract layered on the calculus**, rather than as consequences of abstract linear algebra. That division respects the supplied Tier 2 constraint. fileciteturn0file0

The project specification fixes a reference quinary alphabet \(\{-2,-1,0,+1,+2\}\), coordinate dimension \(d=1024\), sign and magnitude bit planes, invariants \(M_1\land M_2=0\) and \(S\land\neg A=0\), a reference occupancy wall \(K_{\rm wall}=307\), and approximately \(70.02\%\) structural vacuum under that implementation constraint. It further states that binding is intentionally information-losing and that unbinding can terminate in `EXACT`, `AMBIGUOUS`, `UNKNOWN`, or `IMPOSSIBLE`. Those facts are project-level inputs to HTLA, not mathematical consequences established by the present literature survey. fileciteturn0file0 In the replacement paper they should therefore be marked `APPLICATION-SPECIFIC` unless an attached implementation/test artifact independently elevates particular invariants to `VERIFIED`.

The rewrite should also preserve the distinction between **mathematical equivalence after flattening** and **software-semantic equivalence**. For finite \(L\), once an ordering of labels is chosen,
\[
\bigoplus_{\ell\in L}\mathbb R^{n_\ell}
\]
is of course linearly isomorphic to a single Euclidean space whose dimension is the sum of the component dimensions. The point of HTLA is therefore not that flattening is mathematically impossible. Its utility is that the decomposition is retained as typed structure: source and target labels, block admissibility, missingness, and recoverability information survive instead of being erased into offsets. This is a design interpretation of elementary direct-sum algebra, not a claim about a previously unknown vector-space construction.

## Relationship to prior art

The closest mathematical and engineering analogues are complementary rather than interchangeable.

**Named Tensor Notation.** Chiang, Rush, and Barak formalize a tensor as a mapping indexed by a *shape* made from named axes; their notation makes tensor contractions, broadcasting, reductions, indexing, and reshaping explicit by axis name and was designed precisely to eliminate ambiguity about which machine-learning axes an operation acts on. citeturn15view0 That is close to HTLA’s insistence that a label should carry semantic information. But the formal Named Tensor object remains a tensor whose indices range over a collection of axes composing a product-shaped record space. citeturn15view0 HTLA’s direct-sum construction instead takes independently dimensioned component vector spaces as the primary state object and treats an operator as a family of maps \(H_s\to H_t\). Named tensors can certainly *encode or simulate* such data with additional conventions; the defensible distinction is that direct-sum component semantics, Peirce blocks, typed absent components, and partial-unbind status are not intrinsic constructs of the Named Tensor formalism itself. citeturn15view0

**Peirce decomposition and rings with several objects.** Ring theory already supplies the exact structural vocabulary needed for the block calculus. A complete set of orthogonal idempotents decomposes a ring into generalized matrix corners \(e_tRe_s\), and modern treatments explicitly describe this as a Peirce decomposition. citeturn20search9turn20academia48 Mitchell’s “rings with several objects” framework is the classical categorical counterpart: a usual ring behaves like a single-object preadditive category, while multiple objects give hom-groups with additive structure and bilinear composition. The original Mitchell article is *Rings with Several Objects*, *Advances in Mathematics*, DOI `10.1016/0001-8708(72)90002-3`. citeturn14search5turn14search0 HTLA should cite this lineage rather than inventing a label grading that lacks a degree-composition law.

**Categorical machine learning.** Category-theoretic treatments of gradient learning, compositional architecture, optics, functors, and string diagrams are an active research program; Crescenzi’s survey explicitly organizes several of these directions. citeturn16view0 That gives useful context but not a reason to inflate HTLA into a category-theoretic universality result. The ringoid/preadditive-category observation is enough: it accurately identifies the block-composition structure and avoids claims the label semantics do not earn.

**HDC and VSA.** Kanerva’s HDC program and the wider VSA family already treat symbolic computation as algebra over high-dimensional vectors. citeturn13search8turn13academia50 Plate’s HRR construction is a major convolution-based member of that family. citeturn18search0 More importantly for the Nexus correction, Schlegel, Neubert, and Protzel explicitly compare the *approximation quality of non-exact unbinding* and discuss ramifications of non-self-inverse binding operations. citeturn18academia50 Thus Nexus’s decision to make recoverability explicit through typed states is compatible with the known limitations of VSA unbinding. The contribution to emphasize is not the discovery that binding can lose information; it is the decision to make that fact an explicit API-level epistemic result rather than silently returning a vector that looks authoritative.

**Labeled and unit-aware arrays.** xarray describes `DataArray` as a labeled multidimensional array whose dimensions carry names and whose coordinates support label-aware alignment and indexing. citeturn17view2 Pint integrates dimensional/unit semantics with NumPy-like computations, rejecting incompatible dimensional operations rather than treating every array as untyped. citeturn17view3 These are useful engineering analogies for HTLA’s insistence that metadata change which operations are meaningful. They are not evidence for HTLA’s direct-sum operator algebra.

A concise relationship-to-prior-art paragraph suitable for the replacement manuscript is therefore:

> HTLA combines established direct-sum linear algebra, Peirce block decomposition, dimension-changing linear maps, and labeled-state programming conventions with a Nexus-specific recoverability and missingness contract. Named Tensor Notation already formalizes semantically named tensor axes, while xarray and unit-aware numerical libraries demonstrate the engineering value of label- and type-sensitive array operations. Peirce decomposition and preadditive categories provide the established algebraic account of block maps, and HDC/VSA literature already recognizes that unbinding may be approximate or non-exact. citeturn15view0turn20search9turn18academia50turn17view2turn17view3 The paper-specific contribution is the assembly of these ideas into Nexus’s direct-sum ABI together with its deterministic quinary representation contract, typed missingness, explicit recoverability states, and executable subsystem interface. The individual linear-algebraic ingredients are prior art; the claim is about the system-level composition and its falsifiable software semantics. fileciteturn0file0

That is a claim which can survive scrutiny without asking the mathematics to bear more weight than it actually does.

## Core mathematical replacement

Let \(L\) be a finite set of semantic labels. To every \(\ell\in L\) assign a finite-dimensional real vector space
\[
H_\ell=\mathbb R^{n_\ell}.
\]
The heterogeneous labeled state space is
\[
\mathcal H=\bigoplus_{\ell\in L} H_\ell.
\]

An element \(H\in\mathcal H\) is a family \(H=(H_\ell)_{\ell\in L}\) with \(H_\ell\in H_\ell\). Because the index set is finite, this direct sum is linearly isomorphic to an ordinary flattened Euclidean vector space after choosing an ordering. The retained decomposition is nevertheless mathematically meaningful because it supplies distinguished projections and inclusions.

For each label, let
\[
e_\ell:\mathcal H\to\mathcal H
\]
be the projection onto the \(\ell\)-component followed by its inclusion back into \(\mathcal H\). Then
\[
e_\ell^2=e_\ell,\qquad
e_\ell e_m=0\quad(\ell\ne m),\qquad
\sum_{\ell\in L}e_\ell=I_{\mathcal H}.
\]

These identities are immediate from componentwise projection and constitute a complete orthogonal idempotent system. For any
\[
T\in \operatorname{End}(\mathcal H),
\]
insert the identity on both sides:
\[
T
=
\left(\sum_t e_t\right)
T
\left(\sum_s e_s\right)
=
\sum_{t,s}e_tTe_s.
\]

Consequently,
\[
\operatorname{End}(\mathcal H)
=
\bigoplus_{t,s\in L}
e_t\operatorname{End}(\mathcal H)e_s.
\]

This is exactly the Peirce/block decomposition associated with the idempotents, consistent with the standard generalized-matrix treatment of rings possessing complete orthogonal idempotents. citeturn20search9turn20academia48 Each corner
\[
T_{t,s}=e_tTe_s
\]
is equivalently a rectangular matrix
\[
T_{t,s}\in\mathbb R^{n_t\times n_s},
\]
mapping source component \(H_s\) to target component \(H_t\).

Composition follows ordinary block multiplication. If \(T:\mathcal H\to\mathcal K\) and \(S:\mathcal K\to\mathcal G\), then
\[
(ST)_{u,s}
=
\sum_t S_{u,t}T_{t,s}.
\]
No grading law on \(L\) is required. The alternate categorical description has labels as objects and
\[
\operatorname{Hom}(s,t)=\operatorname{Lin}(H_s,H_t),
\]
with matrix addition and ordinary composition. This is a finite preadditive category in the “ring with several objects” sense. citeturn14search0turn14search5

This immediately resolves the legacy categorical error. Suppose a proposed category of labeled spaces defines
\[
\operatorname{Hom}_{\mathrm{HTLA}}(X,Y)
=
\operatorname{Lin}(F(X),F(Y))
\]
for the flattened spaces \(F(X),F(Y)\). Then the induced map on each hom-set is a bijection by definition. The functor is therefore full and faithful on that image. A “faithful but not full” theorem requires additional morphism restrictions—such as a coupling graph that forces selected blocks to vanish. Since such a restriction is not needed for the direct-sum calculus, the standalone universality section should be deleted. This correction follows from the definition supplied in the rewrite specification itself. fileciteturn0file0

For label-weighted similarity, define
\[
B_w(H,K)
=
\sum_{\ell\in L}
w_\ell
\langle H_\ell,K_\ell\rangle_{\ell}.
\]

If every \(w_\ell>0\), then for every nonzero \(H\), at least one \(H_\ell\neq0\), so
\[
B_w(H,H)
=
\sum_\ell w_\ell\|H_\ell\|^2
>0.
\]
Symmetry and bilinearity follow componentwise. Thus \(B_w\) is an inner product.

If \(w_\ell\ge0\) for every label but some \(w_j=0\), choose a nonzero state supported only in \(H_j\). Then \(B_w(H,H)=0\) although \(H\neq0\). The induced quantity
\[
\|H\|_w=\sqrt{B_w(H,H)}
\]
is therefore only a seminorm on the full direct sum. This is the distinction requested by the companion-document guidance in the rewrite specification. fileciteturn0file0

For a general flattened cross-label bilinear form
\[
B_W(H,K)=H^\top W K,
\]
the classification is similarly exact. Symmetry for all \(H,K\) requires \(W=W^\top\). Positive definiteness requires \(H^\top WH>0\) for every nonzero \(H\). Hence \(W\) must be symmetric positive definite for \(B_W\) to be an inner product on the full space. A symmetric but singular positive-semidefinite matrix defines only a semidefinite form and induced seminorm. An indefinite or asymmetric \(W\) can still be useful, but the paper should call it a **compatibility score** or **similarity score**, not an inner product or metric.

Dimension-changing maps require an explicit contract rather than rhetoric about “transdimensional” invertibility. Let
\[
A:\mathbb R^n\to\mathbb R^m.
\]
When \(A\) has a nontrivial kernel, distinct inputs can have identical outputs, so exact recovery is mathematically impossible without extra assumptions. When a Moore–Penrose pseudoinverse is used, it supplies the standard generalized-inverse/least-squares behavior rather than undoing information that the forward map destroyed.

For singular-value decomposition
\[
A=U\Sigma V^\top,
\]
the regularized map used in the supplied worked example is
\[
A_{\lambda}^{\dagger}
=
V(\Sigma^2+\lambda I)^{-1}\Sigma U^\top.
\]
For positive \(\lambda\), this should preferably be called a **Tikhonov-regularized inverse map**, not the Moore–Penrose pseudoinverse. The reason is visible directly in singular coordinates:
\[
A_{\lambda}^{\dagger}A
=
V\,
\operatorname{diag}
\left(
\frac{\sigma_i^2}{\sigma_i^2+\lambda}
\right)
V^\top.
\]
Every nonzero singular direction is attenuated when \(\lambda>0\); this product is not the identity. The notation may retain a dagger with a subscript if project compatibility requires it, but the prose should not imply exact inversion.

Johnson–Lindenstrauss belongs here only as a **distortion theorem for finite point sets**. The classical result permits a finite collection of points to be embedded into dimension
\[
m=O(\varepsilon^{-2}\log N)
\]
while approximately preserving pairwise Euclidean distances, under the theorem’s probabilistic/existence conditions. citeturn20search14turn20search0 It does not say that every dimension-reducing operator is invertible, that semantic content is preserved, or that similarity establishes identity or truth. That restraint is exactly consistent with the Nexus requirement that similarity never be promoted to identity and that information-losing transformations expose recoverability explicitly. fileciteturn0file0

Low-rank block compression is equally standard. If a block has singular-value decomposition
\[
T_{t,s}=U\Sigma V^\top,
\]
its truncated SVD gives the optimal rank-constrained approximation under the standard Frobenius and spectral-norm formulations of the Eckart–Young–Mirsky theorem. citeturn21search3turn21search2 Thus HTLA can legitimately compress each coupling block independently, provided the paper reports the retained rank or approximation tolerance and never converts approximation error into a semantic truth claim.

The clean subsystem boundary is therefore:

```mermaid
flowchart LR
    A[Labeled direct-sum state] --> B[HTLA linear block operator]
    B --> C[Dimension-changing linear morphism]
    C --> D{Recoverability contract}
    D --> E[EXACT]
    D --> F[AMBIGUOUS]
    D --> G[UNKNOWN]
    D --> H[IMPOSSIBLE]
    B --> I[Low-rank block approximation]
    B --> J[Nonlinear transformation]
    J --> K[HTNLA boundary]
```

The four recoverability outcomes and the distinction between HTLA and the nonlinear layer are project-level architectural constraints supplied by Nexus. fileciteturn0file0 A nonlinear operation does not become invertible merely because its input and output components carry labels. If the nonlinear map identifies distinct states, clips values, thresholds them, saturates them, or otherwise destroys information, its inverse contract must reflect that loss. This is particularly important because the supplied Nexus specification explicitly supersedes the older circular-convolution-plus-saturation presentation of binding and requires the current information-losing binding semantics to surface genuine uncertainty instead. fileciteturn0file0

The concentration result should be stated in its established form. For independent mean-zero sub-Gaussian coordinates with a suitable uniform sub-Gaussian scale \(K\), Hanson–Wright controls a quadratic form with the schematic tail
\[
\Pr\!\left(
\left|X^\top A X-\mathbb E[X^\top A X]\right|>t
\right)
\le
2\exp\!\left[
-c\min\!\left(
\frac{t^2}{K^4\|A\|_F^2},
\frac{t}{K^2\|A\|_{\mathrm{op}}}
\right)
\right].
\]
This is the Rudelson–Vershynin form; the operator-norm branch is linear in \(t\), which is precisely why the legacy formula identified in the specification cannot be right at the sub-Gaussian endpoint. citeturn17view0turn22academia0

For heavier \(\alpha\)-sub-exponential tails, Götze, Sambale, and Sinulis prove Hanson–Wright-type results with multi-level concentration and explicit dependence on several norms of the matrix. citeturn16view5turn22academia2 The replacement paper should either quote one of those results faithfully with its hypotheses and exact norm structure or omit the heavy-tail theorem entirely. There is no need to manufacture a compact interpolation formula.

## Evidence synthesis, unresolved hypotheses, and speculative extensions

The \(O(\log|L|)\) gradient statement is the clearest case where the literature points toward a related engineering idea without supporting the claimed theorem. Shazeer and collaborators’ sparsely gated mixture-of-experts work uses conditional computation so only a sparse subset of a much larger expert population is active for a given example, explicitly seeking increased model capacity without a proportional increase in computation. citeturn16view1 Switch Transformers goes further and describes sparsely activated expert models with bounded per-example computational cost as total model capacity grows, while also emphasizing routing complexity, communication, and training instability. citeturn16view2

That analogy supports a weaker HTLA proposition:

> **`INFERRED`** — If the active source/target blocks touched by an example remain bounded independently of \(|L|\), and the routing or coupling lookup mechanism itself avoids scanning the full label set, then arithmetic devoted to the active block maps need not scale proportionally with the total number of labels.

This is a conditional implementation observation, not a theorem that gradient cost is \(O(\log|L|)\). Routing, indexing, communication, loss construction, normalization, or globally coupled parameters can all reintroduce dependence on the total label population. The reviewed MoE papers do not establish a universal logarithmic law. citeturn16view1turn16view2

If the project retains the logarithmic conjecture, it should be explicitly tagged `RESEARCH HYPOTHESIS` and attached to a falsification protocol: hold component dimensions, active coupling degree, optimizer, hardware, batch structure, and numerical precision fixed; increase label cardinality geometrically; separately record forward block arithmetic, routing overhead, backward block arithmetic, communication, peak memory, and total wall time; then compare constant-like, logarithmic, and polynomial scaling models. A claim about total gradient complexity fails if the routing or backward path exhibits systematic super-logarithmic dependence under those controlled conditions. No benchmark values should be inserted until such an experiment is actually run.

The quantum extension has a similar disposition. Gilyén, Su, Low, and Wiebe’s quantum singular-value transformation framework supplies polynomial transformations of singular values through generic block-encoded operators, while Low and Chuang’s qubitization supplies a generic standard-form mechanism for embedding and manipulating operators. citeturn15view4turn18search1 In the sources retrieved for this review, no theorem makes semantic labels, Peirce blocks, or an HTLA decomposition by itself confer a quantum speedup. The admissible paragraph is therefore:

> **`RESEARCH HYPOTHESIS`** — A flattened or structured HTLA operator may in principle be supplied to generic quantum block-encoding or singular-value-transformation machinery when an efficient encoding oracle exists. Current evidence does not establish an HTLA-specific complexity advantage; any such advantage would require an explicit oracle model and end-to-end resource analysis. citeturn15view4turn18search1

Persistent homology is even more remote from the core calculus. Zigzag persistence is designed for situations in which topological objects evolve through both forward and backward inclusions, making it relevant in principle to changing graphs or complexes. citeturn15view6 A dynamic Nexus coupling graph could therefore motivate a future zigzag-persistence study *if* vertices, edges, filtration values, temporal transitions, and the operational meaning of persistent classes are all specified. Nothing in the supplied HTLA specification establishes such a filtration, and coordinate sparsity in a quinary vector is not by itself a persistent-homology construction. fileciteturn0file0 Status: `RESEARCH HYPOTHESIS`.

The `BlockOperator` repair should make the variance of the map explicit in the type direction. If the original operator has block signatures
\[
A_{t,s}:H_s\rightarrow K_t,

\[

The executed implementation uses that rule:

```python
def pseudoinverse(self, rcond: float | None = None) -> "BlockOperator":
    A_plus = np.linalg.pinv(self.dense(), rcond=rcond)

    # Reverse the direction of the map.
    inverse_source_labels = tuple(self.target_labels)
    inverse_target_labels = tuple(self.source_labels)
    inverse_source_dims = dict(self.target_dims)
    inverse_target_dims = dict(self.source_dims)

    row_slices = self._slices(
        inverse_target_labels,
        inverse_target_dims,
    )
    col_slices = self._slices(
        inverse_source_labels,
        inverse_source_dims,
    )

    inverse_blocks = {}
    for target in inverse_target_labels:
        for source in inverse_source_labels:
            inverse_blocks[(target, source)] = A_plus[
                row_slices[target],
                col_slices[source],
            ].copy()

    return BlockOperator(
        source_dims=inverse_source_dims,
        target_dims=inverse_target_dims,
        source_labels=inverse_source_labels,
        target_labels=inverse_target_labels,
        blocks=inverse_blocks,
    )
```

The implementation does use set equality to validate that the ordered label sequences contain the expected labels, but **never uses set iteration to determine positional layout**. Slices are created exclusively by iterating explicit `source_labels` and `target_labels` sequences in their declared order. That satisfies the distinction required by the rewrite brief: sets may be useful for membership/equality checks, but their iteration order is not part of the block-layout ABI. fileciteturn0file0

# Hypervector Linear Transdimensional Algebra
## Labeled Direct-Sum Calculus for Heterogeneous Finite-Dimensional States

### Abstract

This paper specifies a labeled direct-sum calculus for finite-dimensional states whose components may have different dimensions. A state is an element of \(\mathcal H=\bigoplus_{\ell\in L}\mathbb R^{n_\ell}\); linear transformations are block operators between such sums; and the block structure is interpreted through the Peirce decomposition of an endomorphism ring, equivalently as a finite preadditive category (“ring with several objects”). This framing supplies explicit component identities without claiming a group- or semigroup-graded algebra where none has been defined.

The construction combines established linear algebra—direct sums, block matrices, weighted bilinear forms, random projections, regularized inverses, and low-rank approximation—with three system-level commitments: an explicit epistemic-status layer for partial recovery; a deterministic quinary reference encoding with checked bit-plane invariants; and an executable reference implementation whose behavior is tied to concrete tests. The linear calculus does not by itself establish learning-performance advantages, exact inversion of information-losing bindings, or universal efficiency gains. Those matters are either implementation-specific or retained as explicitly falsifiable research hypotheses.

## Status and scope

HTLA is a **Tier 2 subsystem-math source**: it provides local mathematical semantics for Nexus v4 components and must not override Tier 0 architecture. Its claims use the project’s existing vocabulary:

CANONICAL, IMPLEMENTED, VERIFIED, PARTIALLY IMPLEMENTED, ACTIVE DEVELOPMENT, PROPOSED, DESIGN TARGET, EXPERIMENTAL, RESEARCH HYPOTHESIS, APPLICATION-SPECIFIC, HISTORICAL/SUPERSEDED, INFERRED.

The reference geometry supplied by the surrounding Nexus v4 architecture uses a quinary coordinate alphabet,

\[
\{-2,-1,0,+1,+2\},
\]

implemented at \(d=1024\) coordinates using three bit planes:

- sign plane \(S\),
- magnitude planes \(M_1,M_2\),
- activity plane \(A=M_1\lor M_2\).

The reference invariants are

\[
M_1\land M_2=0,
\qquad
S\land \neg A=0.
\]

The reference sparsity wall is \(K_{\mathrm{wall}}=307\), corresponding to approximately \(70.02\%\) structural vacuum in that implementation. This is an executable occupancy constraint of the reference geometry, not a universal mathematical law.

Binding in that reference geometry is deliberately information-losing. Any recovery interface must report one of four epistemic outcomes:

\[
\{\mathrm{EXACT},\mathrm{AMBIGUOUS},\mathrm{UNKNOWN},\mathrm{IMPOSSIBLE}\}.
\]

Consequently, “similar” is not “identical,” absence of evidence is typed missingness rather than a silent zero, and no HTLA inverse should be interpreted as a guarantee of semantic or binding-level recovery.

## Relationship to prior art

The core mathematical ingredients of HTLA are established tools rather than newly introduced mathematics. Direct sums and block operators are standard finite-dimensional linear algebra; the blockwise formulation is naturally expressed through the Peirce decomposition induced by orthogonal idempotent projections. Mitchell’s formulation of a preadditive category as a “ring with several objects” provides the appropriate categorical vocabulary for labeled components and matrix-valued hom-sets. [ams](https://www.ams.org/tran/1974-200-00/S0002-9947-1974-0357503-7/)

Named Tensor Notation is the closest notation-level analogue in modern machine learning. Chiang, Rush, and Barak propose naming tensor axes so that operations become independent of positional axis ordering and can be lifted across additional named axes. HTLA differs in object type: it represents a state as a direct sum of independently dimensioned components, \(\bigoplus_{\ell\in L}\mathbb R^{n_\ell}\), and permits block maps \(\mathbb R^{n_s}\to\mathbb R^{m_t}\) between distinct labeled summands. Named tensors instead organize axes within a tensor and do not, by themselves, prescribe an epistemic recovery status, a quinary bit-plane encoding, or an information-losing binding contract. This is a difference in system assembly and semantics, not a claim that direct sums or block matrices are new. [openreview](https://openreview.net/forum?id=hVT7SHlilx)

Hyperdimensional computing and vector symbolic architecture literature already establishes the use of distributed vectors for composition, bundling, similarity, and approximate retrieval. HTLA should therefore not claim to introduce binding or unbinding in general. Its implementation-specific contribution is to make recoverability explicit through typed outcomes—EXACT, AMBIGUOUS, UNKNOWN, and IMPOSSIBLE—rather than presenting approximate recovery as an unqualified inverse. ## Core mathematics

### Labeled state spaces

Let \(L\) be a finite ordered set of labels and let \(n_\ell\in\mathbb N\) be the dimension associated with each label. Define the labeled state space

\[
\mathcal H_L
=
\bigoplus_{\ell\in L}\mathbb R^{n_\ell}.
\]

An element \(H\in\mathcal H_L\) has the form

\[
H=(H_\ell)_{\ell\in L},
\qquad
H_\ell\in\mathbb R^{n_\ell}.
\]

A fixed ordering of \(L\) gives a flattening isomorphism

\[
\operatorname{flat}_L:
\mathcal H_L
\longrightarrow
\mathbb R^{N_L},
\qquad
N_L=\sum_{\ell\in L}n_\ell.
\]

Flattening is an implementation convenience, not a loss of label metadata when the ordering and component dimensions are retained with the state.

**Claim status:** CANONICAL as local notation; VERIFIED as standard finite-dimensional linear algebra.

### Block operators

For source labels \(S\) and target labels \(T\), let

\[
\mathcal H_S=\bigoplus_{s\in S}\mathbb R^{p_s},
\qquad
\mathcal H_T=\bigoplus_{t\in T}\mathbb R^{q_t}.
\]

A block operator

\[
\mathcal L:\mathcal H_S\to\mathcal H_T
\]

is determined by blocks

\[
\mathcal L_{t,s}\in\mathbb R^{q_t\times p_s},
\qquad
t\in T,\;s\in S,
\]

with action

\[
(\mathcal L H)_t
=
\sum_{s\in S}\mathcal L_{t,s}H_s.
\]

An omitted block is interpreted as the appropriately shaped zero matrix. Composition is ordinary block-matrix composition:

\[
(\mathcal L\circ\mathcal M)_{t,r}
=
\sum_{s\in S}\mathcal L_{t,s}\mathcal M_{s,r}.
\]

The system should preserve an explicit ordered label list for all flattening, slicing, serialization, and reconstruction. Set iteration cannot safely determine a stable component-to-offset correspondence across independent loops.

**Claim status:** CANONICAL / IMPLEMENTED.

### Peirce decomposition and ringoids

For \(\mathcal H=\bigoplus_{\ell\in L}\mathbb R^{n_\ell}\), let

\[
e_\ell:\mathcal H\to\mathcal H
\]

be projection onto the \(\ell\)-th component followed by its inclusion. Then

\[
e_\ell^2=e_\ell,
\qquad
e_\ell e_m=0 \quad (\ell\neq m),
\qquad
\sum_{\ell\in L}e_\ell=I_{\mathcal H}.
\]

The family \(\{e_\ell\}_{\ell\in L}\) is a complete orthogonal system of idempotents. The endomorphism ring decomposes as

\[
\operatorname{End}(\mathcal H)
=
\bigoplus_{t,s\in L}
e_t\operatorname{End}(\mathcal H)e_s.
\]

Each Peirce component is naturally isomorphic to a rectangular matrix space:

\[
e_t\operatorname{End}(\mathcal H)e_s
\cong
\operatorname{Hom}(\mathbb R^{n_s},\mathbb R^{n_t})
\cong
\mathbb R^{n_t\times n_s}.
\]

Equivalently, labels form the objects of a finite \(\mathbb R\)-linear preadditive category:

\[
\operatorname{Hom}(s,t)
=
\mathbb R^{n_t\times n_s},
\]

with addition inherited from matrix addition and composition inherited from matrix multiplication. Mitchell’s term for this structure is a ring with several objects. [ams](https://www.ams.org/tran/1974-200-00/S0002-9947-1974-0357503-7/)

This replaces the incorrect “graded \(\mathbb R\)-algebra” claim. A genuine algebra grading would require an index semigroup or group with a compatible degree law such as \(A_gA_h\subseteq A_{g+h}\). A bare label set supplies no such operation.

**Claim status:** VERIFIED.

### Weighted label forms

Given scalar weights \(w_\ell\in\mathbb R\), define

\[
\langle H,K\rangle_w
=
\sum_{\ell\in L}
w_\ell H_\ell^\top K_\ell.
\]

This is an inner product precisely when every \(w_\ell>0\). In that case,

\[
\|H\|_w
=
\sqrt{\langle H,H\rangle_w}
\]

is a norm.

If \(w_\ell\ge 0\) for all labels but at least one weight is zero, then the construction is only a seminorm on the full space. A nonzero state supported entirely on a zero-weighted component has value zero:

\[
H\neq 0,
\quad
H_j=0\;\text{for }j\neq \ell,
\quad
w_\ell=0
\quad\Rightarrow\quad
\|H\|_w=0.
\]

For a general cross-label kernel, write

\[
\langle H,K\rangle_W
=
\sum_{t,s\in L}
H_t^\top W_{t,s}K_s,
\]

where \(W_{t,s}\in\mathbb R^{n_t\times n_s}\). Under flattening, this is

\[
\langle H,K\rangle_W
=
\operatorname{flat}(H)^\top
\mathbf W
\operatorname{flat}(K).
\]

It is an inner product only if \(\mathbf W\) is symmetric positive definite. If \(\mathbf W\) is symmetric positive semidefinite but singular, it defines a seminorm. If symmetry or positive semidefiniteness has not been established, it is a compatibility or similarity score rather than a metric.

**Claim status:** VERIFIED.

### Dimension-changing maps

A dimension-changing block is simply a linear map

\[
E_{t\leftarrow s}:\mathbb R^{p_s}\to\mathbb R^{q_t}.
\]

When an embedding is constructed by a random projection, the relevant guarantee is a finite-set or finite-point-set distortion statement, not universal pointwise recovery. For a suitable random matrix \(P\in\mathbb R^{m\times n}\), a Johnson–Lindenstrauss construction preserves pairwise distances among a designated finite set \(X\) up to prescribed distortion:

\[
(1-\varepsilon)\|x-y\|_2^2
\le
\|P(x-y)\|_2^2
\le
(1+\varepsilon)\|x-y\|_2^2,
\qquad x,y\in X,
\]

when \(m\) is chosen sufficiently large relative to \(\varepsilon\) and \(|X|\).

This does not imply that \(P^+P\) is near identity for every vector when \(m<n\). A reduction map necessarily has a nontrivial kernel, and pseudoinverse-based reconstruction is an estimator whose distortion must be declared and tested for the relevant data distribution or subspace.

**Claim status:** VERIFIED for the standard projection result; APPLICATION-SPECIFIC for any chosen projection distribution, reconstruction budget, or distortion threshold.

### Low-rank block compression

For each block \(\mathcal L_{t,s}\) with singular values \(\sigma_1\ge\cdots\ge\sigma_r\), let \(\widetilde{\mathcal L}_{t,s}^{(k)}\) be its rank-\(k\) truncated SVD. By the Eckart–Young–Mirsky theorem,

\[
\|\mathcal L_{t,s}-\widetilde{\mathcal L}_{t,s}^{(k)}\|_F^2
=
\sum_{j>k}\sigma_j(\mathcal L_{t,s})^2.
\]

Because the flattened blocks occupy disjoint matrix entries,

\[
\|\mathcal L-\widetilde{\mathcal L}\|_F^2
=
\sum_{t,s}
\|
\mathcal L_{t,s}
-
\widetilde{\mathcal L}_{t,s}
\|_F^2.
\]

Thus the squared global Frobenius error equals—not merely upper-bounds—the sum of squared block errors when each block is approximated independently and the same flattening layout is used.

Blockwise low-rank compression can be useful when the individual blocks are low rank, but it is not guaranteed to outperform a global low-rank factorization. The choice should be driven by measured storage, latency, fidelity, and coupling requirements.

**Claim status:** VERIFIED for the algebraic error identity; DESIGN TARGET or EXPERIMENTAL for any claimed performance advantage.

## Nonlinear boundary

HTLA is linear. Given a block operator \(\mathcal L\), a nonlinear layer may be written as

\[
H^{(k+1)}_t
=
\sigma_t
\left(
\sum_{s\in S}
\mathcal L^{(k)}_{t,s}H^{(k)}_s+b_t^{(k)}
\right).
\]

This construction belongs to the HTNLA boundary rather than the linear HTLA core. Once nonlinearities are introduced, ordinary linear inversion and many blockwise algebraic identities no longer apply. A nonlinear layer cannot be presumed invertible merely because some linear sub-block was invertible.

If labels carry nontrivial group representations, arbitrary coordinatewise nonlinearities may also break equivariance. Equivariant nonlinear extensions require separate conditions on \(\sigma_t\), such as norm-gated or representation-aware maps. Such constructions are outside the load-bearing linear calculus.

**Claim status:** ACTIVE DEVELOPMENT / APPLICATION-SPECIFIC.

## Reference implementation

The reference implementation must retain ordered labels explicitly and must exchange source and target roles when constructing an inverse-shaped operator.

A correct regularized pseudoinverse of

\[
\mathcal L:\mathcal H_S\to\mathcal H_T
\]

has type

\[
\mathcal L_\lambda^+:\mathcal H_T\to\mathcal H_S.
\]

Thus:

- the new target labels are the original source labels;
- the new source labels are the original target labels;
- the \((s,t)\) block of the pseudoinverse is the corresponding source-row, target-column slice of the flattened regularized pseudoinverse.

```python
import numpy as np
from dataclasses import dataclass

@dataclass
class HyperVector:
    components: dict

class BlockOperator:
    def __init__(self, blocks, target_labels=None, source_labels=None):
        self.blocks = {t: dict(row) for t, row in blocks.items()}
        self.target_labels = (
            list(target_labels) if target_labels is not None else list(blocks)
        )
        self.source_labels = (
            list(source_labels)
            if source_labels is not None
            else list(dict.fromkeys(
                s for t in self.target_labels
                for s in self.blocks.get(t, {})
            ))
        )

        self.target_dims = {
            t: next(iter(self.blocks[t].values())).shape[0]
            for t in self.target_labels
            if self.blocks.get(t)
        }

        self.source_dims = {}
        for s in self.source_labels:
            for t in self.target_labels:
                if s in self.blocks.get(t, {}):
                    self.source_dims[s] = self.blocks[t][s].shape [ams](https://www.ams.org/tran/1974-200-00/S0002-9947-1974-0357503-7/)
                    break

    def apply(self, hv):
        result = {}
        for t in self.target_labels:
            y = np.zeros(self.target_dims[t])
            for s, block in self.blocks.get(t, {}).items():
                if s in hv.components:
                    y += block @ hv.components[s]
            result[t] = y
        return HyperVector(result)

    def pseudoinverse(self, regularization=0.1):
        target_dims = [self.target_dims[t] for t in self.target_labels]
        source_dims = [self.source_dims[s] for s in self.source_labels]

        row_offsets = np.cumsum([0] + target_dims)
        col_offsets = np.cumsum([0] + source_dims)

        matrix = np.zeros((row_offsets[-1], col_offsets[-1]))

        for i, t in enumerate(self.target_labels):
            for j, s in enumerate(self.source_labels):
                block = self.blocks.get(t, {}).get(
                    s, np.zeros((target_dims[i], source_dims[j]))
                )
                matrix[
                    row_offsets[i]:row_offsets[i + 1],
                    col_offsets[j]:col_offsets[j + 1],
                ] = block

        u, singular_values, vt = np.linalg.svd(matrix, full_matrices=False)
        regularized_inverse = singular_values / (
            singular_values**2 + regularization
        )
        pseudo = vt.T @ np.diag(regularized_inverse) @ u.T

        inverse_blocks = {}
        for j, old_source in enumerate(self.source_labels):
            inverse_blocks[old_source] = {}
            for i, old_target in enumerate(self.target_labels):
                inverse_blocks[old_source][old_target] = pseudo[
                    col_offsets[j]:col_offsets[j + 1],
                    row_offsets[i]:row_offsets[i + 1],
                ]

        return BlockOperator(
            inverse_blocks,
            target_labels=self.source_labels,
            source_labels=self.target_labels,
        )
```

## Concentration and noise

The prior draft should not claim a universal HTLA concentration theorem from a misapplied Hoeffding argument or from a malformed Hanson–Wright extension.

For independent, centered sub-Gaussian coordinates \(X_i\) with \(\|X_i\|_{\psi_2}\le K\), the Hanson–Wright inequality states that, for a fixed matrix \(A\),

\[
\Pr\left(
\left|X^\top AX-\mathbb E[X^\top AX]\right|>t
\right)
\le
2\exp
\left[
-c
\min
\left(
\frac{t^2}{K^4\|A\|_F^2},
\frac{t}{K^2\|A\|_{\mathrm{op}}}
\right)
\right].
\]

The second regime is linear in \(t\), not quadratic in \(t\). Therefore a proposed “generalization” whose \(\alpha=2\) specialization yields \(t^2/\|A\|_{\mathrm{op}}^2\) does not recover Hanson–Wright and must not be presented as such.  [arxiv](https://arxiv.org/abs/1306.2872)

There is active work on extensions and variants involving sparse or non-sub-Gaussian inputs, including results described as sparse \(\alpha\)-sub-exponential Hanson–Wright inequalities. However, their assumptions, tail parameters, diagonal handling, centering conditions, and matrix norms must be carried through exactly. A generic sub-Weibull formula should not be inserted unless sourced to a theorem whose hypotheses match the proposed HTLA noise model. [sciencedirect](https://www.sciencedirect.com/science/article/abs/pii/S0167715220302017)

For linear Gaussian noise injection,

\[
\widetilde y=y+\gamma\xi,
\qquad
\xi\sim\mathcal N(0,I_m),
\]

the exact second-moment identity is

\[
\mathbb E\|\widetilde y-y\|_2^2
=
\gamma^2m.
\]

By Jensen’s inequality,

\[
\mathbb E\|\widetilde y-y\|_2
\le
\gamma\sqrt m.
\]

This bound follows from Gaussian second moments; it should not be attributed vaguely to “Gaussian concentration.” If noise is added separately to every incoming block contribution, the covariance and the resulting bound depend on the injection convention and number of contributions.

**Claim status:** VERIFIED under the stated Gaussian model.

## Complexity research question

The original unqualified statement that gradients scale as \(O(\log|L|)\) should be retired from the core specification. A block representation alone does not make forward or backward propagation logarithmic in the number of labels. At minimum, an implementation must account for active edges, active blocks, output dimensions, and the cost of routing.

A narrower conditional statement is supportable:

> **RESEARCH HYPOTHESIS:** If a routing mechanism activates at most \(k\) source-to-target blocks per input, each selected block has bounded evaluation and differentiation cost, and routing itself is implemented within a declared cost budget, then the per-input block-computation cost is \(O(k)\) plus routing cost, rather than proportional to all possible label-pair blocks.

Mixture-of-experts systems demonstrate the general conditional-computation principle: only a selected subset of experts is activated per token, decoupling active computation from total stored expert parameters. This does not establish an \(O(\log|L|)\) HTLA gradient theorem. Routing mechanisms can themselves require scoring a large number of labels or experts unless hierarchical, approximate, or otherwise structured.  [research](https://research.google/blog/mixture-of-experts-with-expert-choice-routing/)

A falsification protocol should report:

- \(|L|\), total possible blocks, and active blocks per input;
- router FLOPs, memory traffic, and latency separately from selected-block work;
- forward and backward compute;
- dense, sparse, and hierarchical-routing baselines;
- accuracy or reconstruction fidelity at matched parameter and active-compute budgets.

The hypothesis fails if end-to-end gradient cost grows linearly or worse in \(|L|\) after router cost is included under the stated access model.

## Speculative extensions

Everything in this section is walled off from the core calculus. None is necessary to define or operate HTLA.

### Fisher–Rao label geometry

**RESEARCH HYPOTHESIS.** If a differentiable, normalized family of label-transition distributions \(p_\theta(t\mid s)\) is defined, then the Fisher information matrix may supply a Riemannian metric on the parameter manifold of that distribution. This is ordinary information geometry, not a metric automatically induced by an arbitrary label kernel.

A raw matrix of cross-label weights is not necessarily normalized, differentiable, symmetric, positive semidefinite, or even interpretable as a statistical family. Fisher–Rao statements therefore require a distinct probabilistic model and should not be inferred solely from the weighted form \(\langle H,K\rangle_W\).

### Persistent homology

**RESEARCH HYPOTHESIS.** If the Nexus coupling graph or an explicitly defined transition-weight filtration is a decision-relevant artifact, persistent homology may provide a descriptive stability analysis of its evolving topology.

Persistent homology is mathematically valid for an explicitly defined finite filtration, and standard stability results bound diagram perturbation by filtration-function perturbation under appropriate assumptions. But no load-bearing HTLA theorem currently uses persistent homology. It belongs in a separate exploratory note unless a concrete Nexus v4 decision depends on the resulting topological statistic. ### Heavy-tail robust solvers

**RESEARCH HYPOTHESIS.** Robust residual estimation, median-of-means aggregation, trimming, or Catoni-type estimators may improve empirical stability of block-system solvers under a specified heavy-tailed noise model.

This is not a theorem about all HTLA systems. A usable claim requires an explicit observation model, estimator, loss, preconditioner, and baseline.

### Quantum block encodings

**RESEARCH HYPOTHESIS.** A flattened HTLA operator may be a candidate input to generic quantum block-encoding and quantum singular-value-transformation methods when a concrete efficient access model is supplied.

Block encoding embeds a scaled matrix in a larger unitary, while QSVT provides polynomial transformations of singular values once a suitable block encoding is available. These are general tools. No HTLA-specific quantum advantage follows from labeling alone; the cost of data loading, state preparation, block encoding, conditioning, measurement, and output extraction can dominate. [inspirehep](https://inspirehep.net/literature/2762316)

### Gauge-equivariant nonlinearities

**RESEARCH HYPOTHESIS.** When labels carry specified group representations and blocks are intertwiners, nonlinearities may be designed to preserve equivariance. This requires a representation-aware HTNLA construction and does not follow from the linear direct-sum formalism alone.

### Neural-ODE extension

**RESEARCH HYPOTHESIS.** Time-varying block operators \(\mathcal L(t)\) may be studied with ordinary differential-equation methods if a vector field, state space, regularity conditions, and numerical solver are explicitly declared. No claim about improved training stability is established without an experiment or theorem matching that model.

### Emergent spacetime analogy

**RESEARCH HYPOTHESIS / heuristic only.** Information-geometric quantities may be used as metaphors or exploratory regularization ideas. Writing Einstein-like equations from these quantities is not a derivation of physical spacetime, general relativity, or physical equivalence. The analogy must remain explicitly nonphysical unless and until it is grounded in a separate physical theory and test program.

Core Mathematics of Labeled State Spaces2.1 Direct-Sum State SpaceLet $L = \{\ell_1, \ell_2, \dots, \ell_{\vert{}L\vert{}}\}$ be a finite, ordered set of distinct labels. To each label $\ell \in L$, we associate a finite-dimensional real Hilbert space $\mathcal{H}_\ell = \mathbb{R}^{n_\ell}$ with $n_\ell \in \mathbb{N}_{\ge 1}$. The overall state space $\mathcal{H}$ is defined as the external direct sum:$$\mathcal{H} := \bigoplus_{\ell \in L} \mathcal{H}_\ell = \bigoplus_{\ell \in L} \mathbb{R}^{n_\ell}$$The total dimension of $\mathcal{H}$ is $N = \sum_{\ell \in L} n_\ell$. A state vector $H \in \mathcal{H}$ is represented as a formal sum or labeled family:$$H = \bigoplus_{\ell \in L} H_\ell = (H_{\ell_1}, H_{\ell_2}, \dots, H_{\ell_{\vert{}L\vert{}}})^T, \quad H_\ell \in \mathbb{R}^{n_\ell}$$For each label $\ell \in L$, let $e_\ell: \mathcal{H} \to \mathcal{H}_\ell$ denote the canonical projection operator onto the $\ell$-th component, and let $i_\ell: \mathcal{H}_\ell \to \mathcal{H}$ denote the canonical injection operator. These linear operators satisfy the completeness and orthogonality conditions:$$e_\ell \circ i_m = \delta_{\ell m} I_{\mathcal{H}_\ell}, \quad \sum_{\ell \in L} i_\ell \circ e_\ell = I_{\mathcal{H}}$$where $\delta_{\ell m}$ is the Kronecker delta and $I$ denotes the identity operator.2.2 Block Operators and Mitchell Preadditive Category FramingA linear operator $A: \mathcal{H}_{\text{source}} \to \mathcal{H}_{\text{target}}$ acting between two direct-sum state spaces indexed by label sets $L_s$ and $L_t$ is uniquely partitioned into a collection of block operators $A_{t, s}: \mathcal{H}_s \to \mathcal{H}_t$ for each target label $t \in L_t$ and source label $s \in L_s$:$$A_{t, s} := e_t \circ A \circ i_s \in \mathbb{R}^{n_t \times n_s}$$The full operator $A$ corresponds to the block matrix:$$A = \begin{bmatrix} A_{t_1, s_1} & A_{t_1, s_2} & \cdots & A_{t_1, s_{\vert{}L_s\vert{}}} \\ A_{t_2, s_1} & A_{t_2, s_2} & \cdots & A_{t_2, s_{\vert{}L_s\vert{}}} \\ \vdots & \vdots & \ddots & \vdots \\ A_{t_{\vert{}L_t\vert{}}, s_1} & A_{t_{\vert{}L_t\vert{}}, s_2} & \cdots & A_{t_{\vert{}L_t\vert{}}, s_{\vert{}L_s\vert{}}} \end{bmatrix}$$Algebraic Framing via Peirce DecompositionThe label set $L$ does not possess an underlying semigroup or group structure; consequently, the algebra of operators on $\mathcal{H}$ cannot be classified as a standard graded algebra. Instead, the orthogonal projections $P_\ell = i_\ell \circ e_\ell$ form a complete set of orthogonal idempotents in the endomorphism ring $\text{End}(\mathcal{H})$:$$P_\ell P_m = \delta_{\ell m} P_\ell, \quad \sum_{\ell \in L} P_\ell = I_{\mathcal{H}}$$This idempotent system induces a classical Peirce decomposition of the endomorphism ring $\text{End}(\mathcal{H})$:$$\text{End}(\mathcal{H}) = \bigoplus_{t \in L} \bigoplus_{s \in L} P_t \text{End}(\mathcal{H}) P_s \cong \bigoplus_{t \in L} \bigoplus_{s \in L} \mathbb{R}^{n_t \times n_s}$$Equivalently, the state space structure forms a finite preadditive ($\mathbf{Ab}$-enriched) category $\mathcal{C}_L$ whose objects are the labels $\ell \in L$, whose hom-sets are matrix spaces $\text{Hom}_{\mathcal{C}_L}(s, t) := \mathbb{R}^{n_t \times n_s}$, and whose morphism composition is standard matrix multiplication. This framework maps to Barry Mitchell's formulation of a "ring with several objects".2.3 Label Kernels, Weighted Compatibility, and SeminormsGiven state vectors $H, K \in \mathcal{H}$, a weighted similarity function is defined using a vector of non-negative weights $W_{\text{diag}} = (w_\ell)_{\ell \in L}$ with $w_\ell \ge 0$:$$\langle H, K \rangle_W := \sum_{\ell \in L} w_\ell \langle H_\ell, K_\ell \rangle_{\mathbb{R}^{n_\ell}} = \sum_{\ell \in L} w_\ell (H_\ell^T K_\ell)$$Topological and Metric ConditionsThe weighted similarity structure requires two formal caveats regarding its topological and metric properties:Seminorm Condition: If there exists any label $\ell_0 \in L$ such that $w_{\ell_0} = 0$, the mapping $\Vert{}H\Vert{}_W := \sqrt{\langle H, H \rangle_W}$ is a seminorm, not a norm. A non-zero state vector $H \neq 0$ whose non-zero components reside entirely within zero-weighted subspaces ($H_\ell = 0$ for all $\ell$ where $w_\ell > 0$, but $H_{\ell_0} \neq 0$) satisfies $\Vert{}H\Vert{}_W = 0$.Compatibility Kernels vs. Inner Products: Extending label interactions via a cross-label coupling matrix $W \in \mathbb{R}^{\vert{}L\vert{} \times \vert{}L\vert{}}$ yields:$$\langle H, K \rangle_W := \sum_{t \in L} \sum_{s \in L} W_{t, s} \langle H_t, K_s \rangle$$The mapping $\langle \cdot, \cdot \rangle_W$ defines a valid inner product on $\mathcal{H}$ if and only if $W$ is symmetric ($W = W^T$) and positive definite ($W \succ 0$). If $W$ is symmetric and positive semi-definite ($W \succeq 0$), it defines a positive semi-definite bilinear form. If $W$ is asymmetric or indefinite, $\langle H, K \rangle_W$ represents an asymmetric compatibility score, not an inner product or metric space norm.2.4 Dimension-Changing Morphisms and Hanson-Wright BoundsTransitioning between subspaces of unequal dimension ($n_s \neq n_t$) requires dimension-changing morphisms $T_{t, s}: \mathbb{R}^{n_s} \to \mathbb{R}^{n_t}$.When $n_t < n_s$, dimension reduction can be performed via scaled random projections $T_{t, s} = \frac{1}{\sqrt{n_t}} R$, where $R_{i, j} \sim \mathcal{N}(0, 1)$ or sub-Gaussian equivalent. According to the Johnson-Lindenstrauss (JL) Lemma, for any set of $N$ points in $\mathbb{R}^{n_s}$ and $\epsilon \in (0, 1)$, if:$$n_t \ge \frac{8 \ln(N)}{\epsilon^2}$$then the mapping $T_{t, s}$ preserves pairwise distances up to a factor of $(1 \pm \epsilon)$ with high probability.Concentration Analysis via Hanson-Wright InequalityTo bound distortion on quadratic forms during transdimensional mapping, we apply the standard Hanson-Wright inequality.Let $X = (X_1, \dots, X_{n_s})^T \in \mathbb{R}^{n_s}$ be a random vector with independent, mean-zero, sub-Gaussian components satisfying $\Vert{}X_i\Vert{}_{\psi_2} \le K$. For any deterministic matrix $A \in \mathbb{R}^{n_s \times n_s}$ and any $t \ge 0$, the deviation of the quadratic form $X^T A X$ from its expectation is bounded by:$$\mathbb{P}\left( \vert{}X^T A X - \mathbb{E}[X^T A X]\vert{} > t \right) \le 2 \exp\left( -c \cdot \min\left( \frac{t^2}{K^4 \Vert{}A\Vert{}_F^2}, \frac{t}{K^2 \Vert{}A\Vert{}_{\text{op}}} \right) \right)$$where $\Vert{}A\Vert{}_F = \sqrt{\text{Tr}(A^T A)}$ is the Frobenius norm, $\Vert{}A\Vert{}_{\text{op}}$ is the operator spectral norm, and $c > 0$ is an absolute constant. The second term in the tail exponent scales linearly with $t / \Vert{}A\Vert{}_{\text{op}}$.2.5 Low-Rank Block Compression and SVD RegularizationGiven a block operator $A \in \mathbb{R}^{N \times M}$, singular value decomposition (SVD) factors $A$ as $A = U \Sigma V^T$. To resolve ill-conditioned or rank-deficient block matrices during inversion, HTLA uses Tikhonov-regularized pseudoinverses $A^+_\lambda$:$$A^+_\lambda := V D_\lambda U^T, \quad D_\lambda = \text{diag}\left( \frac{\sigma_1}{\sigma_1^2 + \lambda}, \frac{\sigma_2}{\sigma_2^2 + \lambda}, \dots, \frac{\sigma_r}{\sigma_r^2 + \lambda} \right)$$where $\sigma_i$ are the singular values of $A$ and $\lambda > 0$ is the regularization parameter.3. from typing import Dict, Tuple, List

class LabeledVector:
    """Vector in a direct sum space V = \bigoplus_{l \in L} \mathbb{R}^{n_l}."""
    def __init__(self, data: Dict[str, np.ndarray]):
        self.data = {k: np.array(v, dtype=float) for k, v in data.items()}

    def __repr__(self):
        return f"LabeledVector({self.data})"

class BlockOperator:
    """Linear operator between direct sum spaces A: V_source -> V_target."""
    def __init__(self, blocks: Dict[Tuple[str, str], np.ndarray],
                 source_labels: List[str], target_labels: List[str]):
        self.source_labels = list(source_labels)
        self.target_labels = list(target_labels)
        self.blocks = {(t, s): np.array(B, dtype=float) for (t, s), B in blocks.items()}

    def to_matrix(self) -> Tuple[np.ndarray, Dict[str, int], Dict[str, int]]:
        source_dims = {}
        target_dims = {}
        for (t, s), B in self.blocks.items():
            target_dims[t] = B.shape[0]
            source_dims[s] = B.shape[1]

        total_target = sum(target_dims[t] for t in self.target_labels)
        total_source = sum(source_dims[s] for s in self.source_labels)

        M = np.zeros((total_target, total_source))

        t_offsets, curr = {}, 0
        for t in self.target_labels:
            t_offsets[t] = curr
            curr += target_dims[t]

        s_offsets, curr = {}, 0
        for s in self.source_labels:
            s_offsets[s] = curr
            curr += source_dims[s]

        for (t, s), B in self.blocks.items():
            r = t_offsets[t]
            c = s_offsets[s]
            M[r:r+B.shape[0], c:c+B.shape[1]] = B

        return M, t_offsets, s_offsets

    def pseudoinverse(self, lmbda: float = 0.0) -> 'BlockOperator':
        """
        Computes regularized pseudoinverse M^+_\lambda = V (\Sigma^2 + \lambda I)^{-1} \Sigma U^T.
        Correctly swaps target_labels and source_labels:
        New source = Old target; New target = Old source.
        """
        M, t_offsets, s_offsets = self.to_matrix()
        U, S, Vt = np.linalg.svd(M, full_matrices=False)
        V = Vt.T
        if lmbda > 0:
            S_inv = S / (S**2 + lmbda)
        else:
            S_inv = np.array([1.0/s if s > 1e-12 else 0.0 for s in S])

        M_pinv = V @ np.diag(S_inv) @ U.T

        inv_blocks = {}
        for s in self.source_labels:
            s_idx = s_offsets[s]
            s_len = next(B.shape[1] for (trg, src), B in self.blocks.items() if src == s)
            for t in self.target_labels:
                t_idx = t_offsets[t]
                t_len = next(B.shape[0] for (trg, src), B in self.blocks.items() if trg == t)
                inv_blocks[(s, t)] = M_pinv[s_idx:s_idx+s_len, t_idx:t_idx+t_len]

        return BlockOperator(inv_blocks, source_labels=self.target_labels, target_labels=self.source_labels)

    def apply(self, v: LabeledVector) -> LabeledVector:
        out = {}
        for t in self.target_labels:
            acc = None
            for s in self.source_labels:
                if (t, s) in self.blocks and s in v.data:
                    res = self.blocks[(t, s)] @ v.data[s]
                    acc = res if acc is None else acc + res
            if acc is not None:
                out[t] = acc
        return LabeledVector(out)
