1.1 Spatial and Temporal Compartmentalization (Tripartite Cell)
----------------------------------------------------------------
The fundamental building block of the Biological Tri-Cell Computational 
Architecture (BTCA) is the Tripartite Computational Unit (TCU) [1, 3]. Instead of 
modeling cells as monolithic state machines, the TCU divides cellular function 
into three coupled regulatory domains matching distinct physical and temporal scale 
boundaries [3]:

  * Nucleus (Core-A): The slow-varying identity maintenance and transcriptional
    regulation core [3, 49].
    - Update Cadence: Low priority (stability-focused) [4].
    - Primary State Variables: Lineage/identity label (L_i in [0, 255]) [49], 
      Transcription Factors (TF_homeo, TF_repair, TF_mit, TF_apo) with maximum 
      molecular copy-number limits [4, 8, 49].
    - Energetic Cost: High chromatin/epigenetic update costs to prevent 
      noise-driven state transitions [5, 20].

  * Cytoplasm (Core-B): The high-speed predictive metabolic engine and signal
    processing hub [3, 4].
    - Update Cadence: Medium priority (continuous processing) [4].
    - Primary State Variables: Adenosine Triphosphate (ATP) pool, local tissue 
      consensus estimate (s_hat_i) [50], secondary messengers, and the Predictive 
      Homeostatic Filter (PHF) tracking the delta between received and expected 
      states [6].
    - Energetic Cost: ATP-dependent polymerases for exosome encoding [14].

  * Membrane (Core-C): The reactive physical boundary and communication interface [3, 4].
    - Update Cadence: High priority (immediate reactivity) [4].
    - Primary State Variables: Receptor array counts for vesicle classes (R_{i,k} 
      in [0, R_max]) [4, 51], outbound vesicle queues, and adhesion molecules [4, 61].
    - Energetic Cost: SNARE-mediated membrane deformation costs for vesicle 
      release and target cell internalization [11, 20].

1.2 Intracellular Coupling Graph and Timing
-------------------------------------------
Intra-compartmental synchronization is achieved through a directed, non-Abelian
closed-loop cycle running at asynchronous clock schedules [7]:

  1. Membrane to Cytoplasm (C -> B): Ligand-binding events at the membrane receptor

  3. Nucleus to Cytoplasm (A -> B): The Nucleus responds by emitting synthetic mRNA

  4. Cytoplasm to Membrane (B -> C): Metabolically fueled vesicle formation, SNARE

Each cell i maintains an asynchronous local clock. The phase theta_i(t) advances as [51]:
  theta_i(t + dt) = theta_i(t) + omega_i * dt

  When theta_i(t) >= 1.0, the cell completes one biological cycle, triggers its 
  micro-cycle update schedule, and resets its phase [52]. No global clock or synchronous 
  updates are permitted [17].

1.3 Mathematical Formulation & Diffusion
----------------------------------------
Extracellular chemical dynamics are governed by a hybrid Reaction-Diffusion Master
Equation (RDME) [11, 13]. Let v_k(x, t) represent the extracellular density of exosomal 
vesicles of class k at spatial coordinates x [57]. The continuous field evolution is:

  dv_k(x, t) / dt = D * Laplacian(v_k) - lambda_k * v_k 
                    + sum_i q_{i,k}(t) * delta(x - x_i) 
                    - sum_i uptake_{i,k}(t) * delta(x - x_i)

Where [57]:
  * D is the diffusion coefficient [11].
  * lambda_k is the enzymatic/physical clearance degradation rate [57].
  * q_{i,k}(t) is the point-source emission function of cell i [11, 57].
  * uptake_{i,k}(t) is the receptor-gated internalization rate [57, 59].

Intracellular state transitions obey the following system of coupled ODEs [10]:

  where k_on is the association rate constant [58, 59].

1.4 The 64-Bit Exosomal Substrate Protocol
------------------------------------------
The strict information bottleneck dictates that cell-to-cell communication occurs 
exclusively via the emission of a single 64-bit payload per cycle [2, 46]. This payload is

    00 -> A (Adenine)
    01 -> C (Cytosine)
    10 -> G (Guanine)
    11 -> U (Uracil)

  * Biological Constraints: To prevent structural instability and non-specific
    hybridization errors, the 32-nt RNA sequence is mathematically restricted [13, 22]:
    - No homopolymer runs longer than 3 nt [13].
    - Total GC-content must remain strictly between 40% and 60% [13].

  * 64-Bit Bit-Level Schema (MSB -> LSB) [65]:
    - Bits 60-63 (4 bits): Preamble/version.
    - Bits 52-59 (8 bits): Lineage/identity.
    - Bits 48-51 (4 bits): Vesicle class (message_type k in [0, 15]).
    - Bits 36-47 (12 bits): Consensus estimate (quantized s_hat_i).
    - Bits 24-35 (12 bits): Stress proxy (quantized u_i).
    - Bits 16-23 (8 bits): Local density cue (quantized rho_i).
    - Bits 12-15 (4 bits): Fate/repair flags (Mitosis, Apoptosis, Repair).

  * Internalization Constraints: Each cell's Membrane is limited to a capacity of K_max = 8

1.6 Cell-Aware Lyapunov Homeostasis and Regeneration

To minimize tissue-level entropy and guide local regenerative actions without centralized

  V_i(t) = w_s * (s_i - s_hat_i)^2 + w_u * u_i^2 + w_A * (A_i - A*)^2 + w_rho * (rho_i - rho*)^2

  * u_i is the accumulated stress [62].

  * rho_i is the local cell density, rho* is the optimal density setpoint [62].

  1. Mitosis Trigger: If V_i > threshold and rho_i < rho*, empty adjacent lattices are selected,

  2. Compensatory Signal Amplification: Cells at the boundary of a necrotic lesion increase

  3. Altered Adhesion: Adhesion protein concentrations are downregulated, enabling local cell 
     migration toward the empty necrotic zone to restore tissue connectivity [23, 34, 63].

2.3 Complete Python RNA Transcoder (Runnable Constraint Solver)
---------------------------------------------------------------
The following algorithm dynamically transcodes 64-bit payloads to biological

heuristics if a sequence violates biological boundaries [22, 23]:

```python
import numpy as np

class BiologicalRNATranscoder:
    def __init__(self):
        self.bit_to_nt = {0b00: 'A', 0b01: 'C', 0b10: 'G', 0b11: 'U'}
        self.nt_to_bit = {'A': 0b00, 'C': 0b01, 'G': 0b10, 'U': 0b11}

    def pack_to_rna(self, payload_64: int) -> str:
        """
        Encodes a 64-bit integer into a 32-nt RNA sequence.
        If constraints (GC-content 40-60%, homopolymer run <= 3) fail,
        reversibly perturbs the payload via a deterministic scrambling key.
        """
        scramble_key = 0x5A5A5A5A5A5A5A5A
        attempts = 0
        current_payload = payload_64

        while attempts < 256:
            rna = []
            for i in range(32):
                shift = 2 * i
                two_bits = (current_payload >> shift) & 0b11
                rna.append(self.bit_to_nt[two_bits])
            rna_str = "".join(rna)

            if self.validate_constraints(rna_str):
                # Prepend escape bit indicating scramble depth
                return rna_str, attempts

            # Reversibly mutate the vector to find a stable structural motif
            current_payload ^= (scramble_key + attempts)
            attempts += 1

        raise ValueError("Critical: Failed to resolve biologically viable RNA sequence!")

    def unpack_from_rna(self, rna_str: str, scramble_depth: int) -> int:
        """
        Decodes a 32-nt RNA sequence back to the original 64-bit integer.
        """
        scramble_key = 0x5A5A5A5A5A5A5A5A
        decoded_payload = 0
        for i, nt in enumerate(rna_str):
            two_bits = self.nt_to_bit[nt]
            decoded_payload |= (two_bits << (2 * i))

        # Reverse the scramble operations in inverse order
        for depth in reversed(range(scramble_depth)):
            decoded_payload ^= (scramble_key + depth)

        return decoded_payload

    @staticmethod
    def validate_constraints(rna_str: str) -> bool:
        # Check homopolymers (<= 3 identical runs)
        run_len = 1
        for i in range(1, len(rna_str)):
            if rna_str[i] == rna_str[i-1]:
                run_len += 1
                if run_len > 3:
                    return False
            else:
                run_len = 1

        # Check GC-content (40% to 60%)
        gc_count = sum(1 for nt in rna_str if nt in ('G', 'C'))
        gc_fraction = gc_count / len(rna_str)
        return 0.40 <= gc_fraction <= 0.60
```

  (1 - epsilon) * ||h_i - h_j||^2 <= ||f(h_i) - f(h_j)||^2 <= (1 + epsilon) * ||h_i - h_j||^2

4.1 Riemannian Center of Mass (RCM) Discrete Iterative Approximation
--------------------------------------------------------------------
In a decentralized deployment, computing the global Semantic Continuity Field (SCF)
requires minimizing the sum of squared geodesic distances on the product manifold [127]:

  SCF_global(t) = arg_min_{S in M_HSL} sum_{i=1}^N w_i * d_{HTLA}^2( S, SCF_i(t) )

On a Riemannian manifold, this is approximated numerically via a trust-weighted gradient
descent using exponential and logarithmic mapping operators (the Fréchet Mean) [147, 174]:

  S_k+1 = Exp_{S_k}( delta * sum_{i=1}^N w_i * Log_{S_k}( SCF_i ) )
  where Exp and Log map between the manifold and the tangent space [129].

```python
def discrete_riemannian_center_of_mass(local_fields, weights, max_iter=10, tolerance=1e-5):
    """
    Computes the Fréchet Mean (RCM) of a set of high-dimensional hypervectors.
    """
    # Initialize with the weighted Euclidean average
    rcm = np.average(local_fields, axis=0, weights=weights)
    rcm = rcm / np.linalg.norm(rcm)  # Project back onto the hypersphere manifold

    for iteration in range(max_iter):
        tangent_update = np.zeros_like(rcm)
        total_weight = 0.0

        for field, w in zip(local_fields, weights):
            # Geodesic Logarithmic Mapping: Log_x(y) = theta * u
            cos_sim = np.clip(np.dot(rcm, field), -1.0, 1.0)
            theta = np.arccos(cos_sim)

            if np.abs(theta) > 1e-9:
                u = (field - cos_sim * rcm) / np.sin(theta)
                tangent_update += w * (theta * u)
            total_weight += w

        tangent_update /= total_weight
        norm_update = np.linalg.norm(tangent_update)

        if norm_update < tolerance:
            break

        # Geodesic Exponential Mapping: Exp_x(v) = cos(||v||)*x + sin(||v||)*(v/||v||)
        rcm = np.cos(norm_update) * rcm + np.sin(norm_update) * (tangent_update / norm_update)
        rcm = rcm / np.linalg.norm(rcm)

    return rcm
```

tissue.

A nanobot/swarm should independently determine whether local sensed conditions
match the expected tissue/damage context before activating high-impact behavior.

5.3 Capability Is Not Authority
-------------------------------
A central architectural invariant is:

  CAPABILITY != AUTHORITY

A general-purpose nanobot may physically possess mechanisms that could support
multiple tasks, but it must not have standing permission to activate all of them.

The most privileged capabilities include, at minimum:

  - replication;
  - differentiation/state conversion;
  - persistent engraftment;
  - tissue remodeling;
  - long-lived secretion of growth signals;
  - irreversible local structural change;
  - transfer of persistent program state to other cells/agents.

These operations require stronger authorization and stronger local verification
than ordinary sensing, messaging, or reversible maintenance activity.

================================================================================
SECTION 6: GENERAL-PURPOSE REPAIR MODEL
================================================================================

6.1 Tissue Repair Is a Mission, Not a Nanobot Species
-----------------------------------------------------
A repair mission is represented conceptually as a temporary task profile loaded
onto the common nanobot chassis.

The task profile may specify:

  - target condition class;
  - expected local biomarkers/physical features;
  - allowed action set;
  - forbidden action set;
  - maximum duration;
  - maximum resource expenditure;
  - maximum local swarm density;
  - maximum replication authority, normally zero unless explicitly enabled;
  - success criteria;
  - abort criteria;
  - disposal/quiescence behavior.

6.2 Navigation Does Not Require a Microscopic GPS
-------------------------------------------------
The original concept remains: nanobots need not maintain a complete internal map
of the body.

Navigation can be formulated as a hierarchy of cues:

  1. External coarse guidance from the control plane.
  2. Flow-assisted transport through the body.
  3. Local chemical/biophysical gradients.
  4. Receptor-defined tissue context.
  5. Local damage/inflammation/structural cues.
  6. Swarm-to-swarm/local-neighbor signaling.
  7. Final local verification before task activation.

The exact navigation mathematics are NOT canonical in this addendum. Earlier
conversation-level chemotaxis equations are explicitly classified as illustrative
toy models pending the audit defined in Section 11.

6.3 Stem-Cell-Like Repair Versus Permanent Stem-Cell Identity
-------------------------------------------------------------
The architecture does not require every nanobot to permanently be a pluripotent
stem cell.

The biohybrid stage may use living cells because natural cells provide useful
metabolism, sensing, synthesis, and repair machinery. However, unrestricted
pluripotency and unrestricted proliferation are safety liabilities.

The preferred abstraction is:

  programmable regenerative behavior

rather than:

  permanently free-roaming pluripotent stem cell

The fully synthetic endpoint should reproduce only the capabilities needed for a
mission, not every behavior of a natural stem cell.

================================================================================
SECTION 7: THE CENTRAL SAFETY PROBLEM - PREVENTING PATHOLOGICAL GROWTH
================================================================================

7.1 Terminology
---------------
The term "metastasis" is used colloquially in project discussion to describe a
swarm or engineered-cell population spreading and growing where it should not.

For technical work, the failure classes must be distinguished:

  - uncontrolled proliferation;
  - tumorigenicity;
  - neoplastic transformation;
  - teratoma formation from residual pluripotent cells;
  - ectopic engraftment;
  - inappropriate differentiation;
  - unwanted migration/dissemination;
  - escape from apoptosis;
  - mutation or silencing of safety circuitry;
  - pathological growth-factor signaling;
  - command/control loss;
  - swarm-state corruption.

7.2 Why General Purpose Increases the Safety Burden
---------------------------------------------------
A general-purpose chassis is desirable because it reduces fleet complexity.
However, generality also increases the number of actions a compromised agent may
be physically capable of performing.

Therefore the system must enforce separation between:

  - what the chassis CAN do;
  - what the current mission MAY do;
  - what local conditions justify;
  - what the safety kernel will permit.

7.3 Defense in Depth
--------------------
No single anti-proliferation mechanism is sufficient.

The research architecture should investigate independent containment layers such
as:

  - bounded replication authority;
  - density/contact-dependent inhibition;
  - resource-dependent replication limits;
  - finite mission lifetime;
  - integrity-dependent task execution;
  - independent apoptosis/disposal mechanisms;
  - local tissue-context verification;
  - external revocation;
  - swarm quorum requirements for privileged actions;
  - anomaly detection for lineage/state drift;
  - population caps;
  - replication accounting;
  - fail-closed behavior after communication loss;
  - non-replicating fallback modes;
  - removal by immune-compatible or external service mechanisms.

These are architectural research requirements, not claims that present biology
can implement them perfectly.

7.4 Safety Circuits Must Be Treated as Fallible
-----------------------------------------------
A kill switch, apoptosis trigger, contact-inhibition rule, or other containment
mechanism must never be modeled as infallible.

The simulation program must include failure modes such as:

  - switch mutation;
  - switch silencing;
  - receptor loss;
  - false-negative context sensing;
  - false-positive repair activation;
  - signal spoofing/corruption;
  - local resource-model failure;
  - partial controller isolation;
  - multiple simultaneous safety-layer failures.

The safety question is therefore not:

  "Does the system have a kill switch?"

It is:

  "What is the probability and consequence of escape when one or more independent
   containment layers fail?"

SECTION 8: NANOBOT INTERNAL ARCHITECTURE - LOGICAL TARGET

8.1 Common Logical Modules
--------------------------
The long-term general-purpose synthetic nanobot should be designed around common
logical modules even if their physical implementation changes across generations:

  1. Identity and Integrity Core
     - persistent identity;
     - version/provenance;

     - lineage/task authorization state.

  2. Sensor Interface
     - local chemical cues;
     - local physical cues;

  3. Local State and Task Engine
     - bounded state machine;
     - task authorization;
     - local context verification;
     - abort/rollback state.

  4. Communication Interface
     - constrained local messages;
     - swarm summaries;
     - external-control interface where physically possible;
     - authentication/integrity appropriate to the substrate.

  5. Energy/Resource Controller
     - energy acquisition;
     - energy accounting;
     - task-energy limits;

  6. Actuation/Repair Interface
     - movement or adhesion change;
     - material transport;
     - local secretion/deposition;

  7. Safety Kernel
     - privileged-operation gating;

  8. Maintenance Interface
     - external microrobot/DNA-machine interaction;

     - calibration;

8.2 Substrate Independence
--------------------------
The logical architecture should remain stable while the physical substrate
changes:

  GENERATION 1:
    Logical Nanobot Runtime -> Biological Adapter -> Living Cell

  GENERATION 2:
    Logical Nanobot Runtime -> Hybrid Molecular Adapter -> Augmented Living Cell

  GENERATION 3+:
    Logical Nanobot Runtime -> Synthetic Molecular Runtime -> Synthetic Chassis

This is intentionally aligned with the broader Nexus principle of preserving
functional organization while allowing the implementation substrate to change.

SECTION 11: MANDATORY DCSI + BTCA MATHEMATICS AND CHEMISTRY AUDIT
================================================================================

11.1 Audit Gate
---------------
BEFORE constructing or canonizing the actual nanobot mathematics, the existing
DCSI, BTCA, Triskelion Master Specification, and Addendum A equations MUST be
audited line by line.

No equation may be inherited merely because it appears in an older master
specification, a NotebookLM/Gemini-generated synthesis, a podcast, a model answer,
or an earlier research document.

11.2 Required Classification Labels
------------------------------------
Every equation, numerical constant, kinetic rule, scaling law, and claimed
physical constraint must receive one or more of the following labels:

  [DERIVED]
    Follows from stated assumptions by an explicit derivation that can be checked.

  [BIOLOGICALLY GROUNDED]
    Form and/or parameterization is supported by identifiable experimental or
    peer-reviewed biological literature for the relevant substrate and regime.

  [PHYSICALLY GROUNDED]
    Form and/or parameterization follows from established physical law in the
    relevant scale/regime.

  [SIMULATION ASSUMPTION]
    Deliberately imposed to define the experiment; not claimed as a law of nature.

  [HEURISTIC]
    Useful engineering/controller approximation without a formal derivation or
    direct biological equivalence.

  [DIMENSIONALLY SUSPECT]
    Units do not obviously close, variables mix counts/concentrations/probabilities,
    or the equation requires missing dimensional factors.

  [UNSUPPORTED]
    No adequate source, derivation, experimental result, or stated modeling reason
    currently supports the claim.

  [CONTRADICTORY]
    Conflicts with another canonical constraint or equation.

  [TERMINOLOGY ERROR]
    Mathematical, chemical, biological, or physical terminology is used in a way
    that changes or obscures its technical meaning.

  [UNKNOWN]
    Status cannot yet be determined and requires targeted research.

11.3 Required Audit Record for Every Equation
---------------------------------------------
For every equation E_j, the audit must record:

  Equation ID:
  Source filename:
  Source section/line/page:
  Original equation:
  Intended meaning:
  Variables:
  Units for every variable:
  Domain/range:
  Time/space scale:
  Derivation or source:
  Classification label(s):
  Dimensional analysis:
  Hidden assumptions:
  Known failure modes:
  Numerical implementation concerns:
  Whether the equation is local or observer-side:
  Whether a nanobot can physically access every required variable:
  Whether the equation violates bandwidth/memory/energy constraints:
  Falsification or test method:
  Recommended action: KEEP / REWRITE / REPARAMETERIZE / QUARANTINE / DELETE

-------------------------

11.5 Preliminary Audit Flags Already Identified
-----------------------------------------------
The following items are NOT a completed audit. They are known issues that must be
entered into the formal audit queue.

A. RECEPTOR-BINDING DIMENSIONALITY

Current form appearing in the BTCA/master material:

  p_bind = 1 - exp(-k_on * R_free * dt)

If k_on is expressed as a conventional bimolecular association constant in
concentration^-1 time^-1, multiplying it directly by a receptor COUNT and time
does not produce a dimensionless exponent. The model must explicitly distinguish
receptor count, receptor surface density, ligand concentration, encounter rate,
and pseudo-first-order approximations.

Status:
  [DIMENSIONALLY SUSPECT]
  [REQUIRES REWRITE]

B. 32-NT RNA == 64 RAW BITS

The mapping:

  4 nucleotide symbols -> 2 raw bits per nucleotide
  32 nucleotides -> 64 raw theoretical bits

is an information-capacity abstraction. It is not automatically equivalent to 64
reliable application bits after sequence constraints, coding redundancy,
recognition requirements, degradation, framing, error correction, and biological
implementation overhead.

The term "32-bp RNA" is also incorrect unless a duplex is specifically intended.
A single RNA sequence should normally be described as 32 nt.

Status:
  raw mapping: [DERIVED]
  reliable biological payload claim: [UNSUPPORTED] until channel model exists
  "32-bp RNA": [TERMINOLOGY ERROR] where single-stranded RNA is intended

C. ADDENDUM A RNA SCRAMBLE SIDE-CHANNEL PROBLEM

The current Addendum A transcoder returns both:

  rna_str
  scramble_depth

but the strict 32-nt/64-bit channel does not visibly encode scramble_depth inside
the same payload. A receiver therefore requires side information to reverse the
scrambling, violating the claim of a self-contained strict 64-bit channel unless a
new in-band coding scheme is defined.

Status:
  [CONTRADICTORY]
  [REQUIRES REWRITE]

D. CONNECTIVITY/PERCOLATION CONSTANT

The DCSI material currently uses a constant-style condition resembling:

  pi * R_c^2 * N / A > 4.5

and describes it as ensuring connectivity.

A constant mean-degree/percolation threshold is not generally identical to a full
connectivity guarantee for a random geometric graph. Connectivity, giant-component
formation, k-connectivity, boundary effects, dimensionality, and post-lesion
connectivity must be separated.

Status:
  [HEURISTIC] or [SIMULATION ASSUMPTION] unless properly derived
  [UNSUPPORTED] as a universal connectivity guarantee

E. XOR USED AS "REINFORCEMENT"

XOR can be useful as a binary binding/difference operation, but XOR by itself does
not mean consensus reinforcement. Consensus/bundling and binding must be separated.
Majority/bundling, weighted accumulation, Hamming similarity, and XOR binding
should not be conflated.

Status:
  [TERMINOLOGY/OPERATOR ERROR]
  [REQUIRES REWRITE]

F. HSL DISTANCE/METRIC CLAIM

A composite expression combining physical distance, hypervector similarity, and
salience difference is not automatically a valid Riemannian metric. Normalization,
metric properties, triangle inequality, topology, and manifold assumptions must be
proved or the quantity should be called a dissimilarity/energy functional.

Status:
  [UNSUPPORTED] as a formal Riemannian metric until proven
  [HEURISTIC] as a simulation dissimilarity if explicitly declared

G. CHEMOTAXIS/NAVIGATION EQUATIONS FROM CURRENT DISCUSSION

Any previously proposed single-gradient equation of the form:

  velocity = gradient response + flow + noise

is a toy intuition only. It omits receptor adaptation/saturation, adhesion,
extravasation, stochastic persistence, geometry, tissue mechanics, multi-cue
integration, and other factors.

Status:
  [HEURISTIC]
  [NON-CANONICAL]

H. ONE VESICLE PER CYCLE VS "INCREASE EMISSION RATE"

The master/BTCA materials simultaneously state a strict one-vesicle-per-cycle
communication bottleneck and describe lesion-boundary cells as increasing vesicle
emission rate.

The model must specify whether "increase" means:

  - shorten the biological cycle;
  - increase payload priority;
  - increase release probability;
  - emit more than one vesicle, thereby violating the constraint;
  - or something else.

Status:
  [CONTRADICTORY]

I. "HILL" FUNCTION WITHOUT HILL EXPONENT

Addendum A uses a rectified saturating function resembling:

  H(z;k) = max(0,z) / (max(0,z) + k)

This is a saturating response with an implicit exponent of 1, not a general Hill
function unless the modeling decision is explicitly stated. Claims of biological
validation require parameter-specific sources.

Status:
  [HEURISTIC] unless sourced and parameterized
  [TERMINOLOGY CLARIFICATION REQUIRED]

J. BIOLOGICAL CONSTANT TRANSFER ACROSS SUBSTRATES

Constants or energy budgets borrowed from one organism or cell type must not be
silently transferred to mammalian cells, engineered cells, synthetic cells, or
future nanobots. Values such as power budgets, receptor rates, diffusion ranges,
and ATP costs must be tied to the relevant substrate.

Status:
  [UNSUPPORTED] when cross-substrate transfer lacks justification

K. PHI-PROXY STATUS

The existing Phi-proxy is an engineering observer/controller metric unless a
separate derivation demonstrates equivalence to a specific formal theory. It must
not be presented as direct proof or measurement of consciousness.

Status:
  [HEURISTIC]
  [OBSERVER-SIDE METRIC]

L. JL / SIMHASH / COLLISION CLAIMS IN ADDENDUM A

The Johnson-Lindenstrauss, SimHash, collision, and projection sections require
fresh mathematical review. In particular:

  - constants in JL bounds are theorem/assumption dependent;
  - projected dimension should not casually be described as "bits" when the
    mathematical object is a real-valued embedding dimension;
  - exact sketch equality probability is not the same as false consensus under a
    similarity threshold;
  - nearest-neighbor dictionary effects require a proper multiple-comparison model;
  - a low raw collision probability does not by itself "validate" semantic
    transmission.

Status:
  [REQUIRES FORMAL RE-DERIVATION]

M. RIEMANNIAN CENTER-OF-MASS ASSUMPTIONS

The Addendum A Riemannian mean code appears to operate on normalized vectors on a
unit hypersphere. That does not automatically implement a general HSL manifold.
The manifold, metric, normalization, curvature assumptions, and local-vs-global
availability must be explicit.

Status:
  [SIMULATION ASSUMPTION] if restricted to a hypersphere model
  [UNSUPPORTED] as a universal HSL implementation

N. GLOBAL VARIABLES INSIDE A LOCAL-ONLY ARCHITECTURE

Any equation requiring a global field, global mean, global center, or all-node
state must be classified as either:

  - observer-side telemetry;
  - an offline analysis quantity;
  - or a distributed approximation computed from local messages.

A nanobot cannot use a variable it cannot physically observe or reconstruct.

Status:
  [ARCHITECTURAL CONSISTENCY CHECK REQUIRED]

11.6 Audit Rule for Numerical Constants
---------------------------------------
Every numerical constant must answer:

  WHY THIS NUMBER?

Permitted answers include:

  - experimentally measured value for the relevant substrate;
  - derived physical constant;
  - value chosen by dimensional scaling;
  - parameter sweep range;
  - explicit simulation stress-test value;
  - fitted parameter with dataset/procedure;
  - placeholder marked UNKNOWN.

"Research validated" without a traceable source is not an acceptable provenance
label.

11.7 Audit Rule for Units
-------------------------
Every physical equation must pass dimensional analysis before implementation.

Counts, concentrations, probabilities, rates, energies, powers, lengths, times,
velocities, diffusion coefficients, receptor densities, and dimensionless control
states must not be mixed without explicit conversion.

11.8 Audit Rule for Accessibility
---------------------------------
Every state variable used by a nanobot controller must be classified as:

  LOCAL SENSOR VALUE
  LOCAL INTERNAL VALUE
  NEIGHBOR-DERIVED VALUE
  EXTERNAL COMMAND VALUE
  OBSERVER-ONLY VALUE

Observer-only values are forbidden inside the nanobot control loop.
